# 盖一块：模糊 / 马赛克（形状的一种）

> 2026-09-29 引入（MCP 方案第 56 条：遮水印、遮烧进去的旧字幕）。改 `ShapeKind.blur` / `.mosaic`、`VideoEditCoverExport`、
> `CoverPreviewLayer`、`CoverFilters`、`AICoverBox` 之前必读。相关：[滤镜](filters.md)（落点在调色之后、预览不走自定义合成器）、
> [画面文字](text-overlays.md)（层序）、[段的显隐](clip-visibility.md)（`renderedCovers`）、[AI 接口（MCP）](ai-control-mcp.md)。

## 落点：形状的一种、时间线上的一段，不是片段的属性

| 决定 | 口径 |
| --- | --- |
| 是什么 | `ShapeKind.blur` / `.mosaic`（`isCover`）。**不画东西**：把它下面的画面模糊或打马赛克。长方形的几何；时间线上的形状行里的块（青色）、选中框、拖动、两端裁切、V 隐藏、复制粘贴，全是形状那一套 |
| 盖谁 | 这段时间里主轨 + 上层轨**合成之后、调色之后**的整幅画面；形状 / 文字 / 字幕压在它上面，不被盖 |
| 总长 | **不算**（同滤镜段：盖在空白上没有意义）；只剩一块盖一块的工程不算空工程（它是用户的操作，不能被当成空的丢掉） |
| 力度 `coverAmount` | 模糊 = 高斯的标准差、马赛克 = 每格的边长，都是 1080p 基准的像素；2…80，默认模糊 28、马赛克 22（一行 40 像素高的字，28 糊到认不出、22 只剩两格高）。按**画面高**换算到各管线（竖屏 1920 高就放大 1.78 倍） |
| 位置 | 画布的 0…1 归一化（不是源画面的）。**不跟着片段走**：挪 / 缩放片段之后要重盖，见下一节 |
| 清单 | `renderedShapes`（画出来的）**不含**盖一块；`renderedCovers`（预览的第二层和导出都读它）是没藏起来的盖一块，按数组顺序（先加的先盖） |
| 存盘 | 工程格式 v26（`requiresFormatVersion26`）：只有盖一块落 `coverAmount`；只认 v25 的旧版会把不认识的种类宽容回落成长方形，该糊的地方变成一圈描边、水印露出来，所以要抬版本 |

## 为什么不挂在片段上（方案第 56 条的取舍）

方案原本打算「挂在片段上、跟着那段素材走」。这一版做成时间线上的一段（同滤镜、形状），理由：

1. **预览不走自定义合成器**（[滤镜](filters.md) 的地基）：片段上的效果没有钩子，只能靠第二层播放器 + 蒙版；蒙版还得跟着片段的摆放（含关键帧动画）
   逐拍换算 —— 多一个订阅时钟的东西、多一条关键帧路径。
2. 落在片段上，分割、复制、链接、拷贝粘贴、`cut_speech` 每处「从旧段构造新段」都要把它带上 —— 这类漏字段已经出过两个案例
   （[分割丢了隐藏和音频库的键](../bugfixes/2026-09-26-split-drops-hidden-and-library-key.md)）。
3. 时间线上的一段，选中 / 拖动 / 裁切 / 隐藏 / 复制粘贴已经全有。

代价：片段挪了、缩放了，盖一块不跟着走。缓解：AI 拿到的画布坐标是按片段**当前**的摆放算的（`look text_scan` 的 `cover`，下面「AI」一节）。
要跟着走是后续的事，要先解决第 1 条。

## 三条管线：按构造一致 —— 裁出这一块、在这块里做效果、边缘往外延、贴回去

| | 预览 | 导出（ffmpeg） | AI 的「看」 |
| --- | --- | --- | --- |
| 载体 | 同一个 AVPlayer 再开的 `AVPlayerLayer`，外层只有这一块大小（`masksToBounds`）、里面的播放器层平移对齐、图层滤镜挂在外层（`CoverHostView`） | `split → crop → gblur / pixelize → overlay(enable=between(t,…))`（`VideoEditCoverExport`） | CoreImage 裁出这一块 → 滤镜 → 贴回（`CoverCompositing`） |
| 滤镜与参数 | `CoverFilters`：`CIAffineClamp` + `CIGaussianBlur` / `CIPixellate` | `gblur=sigma:steps=3` / `pixelize=w:h:mode=avg` | 同预览（`CoverFilters`） |
| 半径 / 格子的单位 | 点：力度 × 预览框高 / 1080 | 像素：力度 × 画布高 / 1080 | 像素，同导出 |
| 这一块的框 | 归一化 → 视图坐标（CA 是左下原点，换一下） | `pixelRect`：取偶数往外收、收进画布 | 同 `pixelRect` |
| 层序 | 播放器视图（调色）→ 第二层（**先调色**再盖）→ 形状 / 文字 / 字幕 / 变换框 | 合成 → 调色 → **盖一块** → 形状 → 文字 → 字幕 | 视频 → 调色 → 盖一块 → 形状 → 文字 → 字幕 |

八条硬约束（改任何一条之前想清楚另外两边）：

1. **层序只有一个说法：调色之后、形状之前。** 预览里调色是挂在播放器视图上的 `contentFilters`，第二层看不到，所以这一层的滤镜链要**先带上调色**
   （`FilterStack.ciFilters()`）再盖 —— 盖的是调完色的画面。
2. **蒙版和滤镜别挂在同一层再靠 mask 裁。** 实测：那样滤镜的输入被蒙版先裁了，块边上和透明混出一圈灰（马赛克那块四周一圈灰框）。
   外层只有这一块大小、`masksToBounds`，滤镜挂外层。
3. **边缘往外延**（`CIAffineClamp`；ffmpeg 的 `gblur` 天然边缘外延）：不外延，块边上一圈会发暗。
4. **马赛克的格子从这一块的左上角起算。** `CIPixellate` 的 `inputCenter` 是格子的一个**角点**（实测水平格线落在 0、12、24…），竖直方向默认从底边起算、顶上留半格；
   设成 `(0, 区域高)` 才和 ffmpeg 的 `pixelize`（天然从左上）一样。
5. **框取偶数、往外收**：yuv420 的 `crop` / `overlay` 要偶数对齐，不取偶数 overlay 会错一个像素。
6. **高斯半径是标准差**，两边一个意思；`gblur` 的 `steps=3` 和理想高斯阶跃响应最大差 2%（`steps=1` 是 6%，更多的每帧白花 CPU）。
7. **力度按画面高换算**，不是画面宽（竖屏按 1920 高）。
8. **没有盖一块时预览不建第二层**（`PreviewPlayerSurface` 里 `if !covers.isEmpty`，性能计数和没这个功能时一样）；有的时候它跟着 `PreviewPlayerSurface`
   已经有的那个时钟订阅更新，不新增订阅者。

## 实测的地基（2026-09-29 窗口探针）

- 同一个 AVPlayer 上挂第二个 `AVPlayerLayer`，`videoGravity` 和播放器视图一样（`resizeAspect`）时两层画面重合、同步，不多解码。
- `CALayer.filters` 对 `AVPlayerLayer` 生效；`CIGaussianBlur` 的半径、`CIPixellate` 的格子边长，单位是**点**（视网膜屏 2 倍缩放后是 2 倍像素）。
- 区域容器（外层裁出这一块）+ 边缘外延：模糊、马赛克都只出现在矩形内，改动的行正好是块的上下沿（±2 点）。
- ffmpeg `gblur` 对理想高斯阶跃响应的最大误差（红蓝交界、σ = 14，255 满幅）：`steps=1` 15.9、`2` 8.5、`3` 5.8、`4` 4.8、`6` 3.4。

## AI（MCP）

- `set_shape` 认 `kind=blur|mosaic` 和 `strength`（2…80）。不画东西：没有颜色 / 线宽 / 实心 / 旋转；写回给 AI 的带 `strength`、`height`，不带 `color`。
  工具说明里的种类词表和 `ShapeKind` 逐项对账（`scripts/check-mcp.sh` 第 25 项）。
- **`look text_scan` 对时间线上的一段**（`AICoverBox`）：把源画面上的框换成画布上的（裁切 → 翻转 → 缩放进摆放框 → 绕框中心旋转，同
  [预览自由变换](preview-free-transform.md) 的变换顺序），给出 `cover`：`x`、`y`（中心）、`width`、`height`（画布的比例）、`start`、`duration`（时间线秒），
  直接抄给 `set_shape`。字幕带盖**整条画面宽**（报出来的左右不可靠，[案例](../bugfixes/2026-09-29-text-scan-cutoff-text-and-sparse-subtitles.md)）；
  水印四周留一圈；会跳角的水印每处一块。只按此刻的摆放换算，不看关键帧动画。
- 盖完调 `look`（时间线）核对：`AIFrameComposer` 合成时盖上（`CoverCompositing`，和预览同一份 `CoverFilters`）。

## 已知不足

- **不跟着片段走**（见上）。
- 盖的是整幅合成（含上层视频轨），预览和导出一样；不是「只盖某一条轨」。
- 预览的 `CIPixellate` 和导出的 `pixelize` 取样方式不同：格子边长一样，格子里的颜色略有差别。
- 预览里点一块没选中的盖一块选不中（它没有可见的内容，也不拦点击，免得挡住下面的剪辑）：在时间线上选它，选中后才有虚线框和拖动 / 缩放的把手。
- 关键帧动画的片段：AI 给的画布坐标是没动画时的。会动的水印要靠跟踪，不做。
