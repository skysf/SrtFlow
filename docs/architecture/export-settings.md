# 导出设置：分辨率档位、面板上放什么、撞名与记住

压缩、烧录字幕、剪辑导出三个工具共用一套编码设置（`VideoEncodeSettings`）。本文只写
**长期约束**；剪辑导出面板的产品决策和理由见
[导出面板改版方案](../plans/2026-09-24-export-panel.md)。

## 一、分辨率档位封的是短边

`ResolutionLimit` 的 2160p / 1440p / 1080p / 720p / 480p 说的是**短边**
（`maxShortSide`）：「1080p」对横屏是 1920×1080，对竖屏是 1080×1920。

1. **只降不升**：短边不超过上限就原样输出。「选 1080p」的意思是「不超过 1080p」，
   不是「变成 1080p」。
2. **横竖要分清**：以前封的是高度，竖屏 1080×1920 选 1080p 被缩成 608×1080
   （[案例](../bugfixes/2026-09-24-resolution-cap-shrinks-portrait-video.md)）。
   判断横竖要**宽高两个都知道**，缺一个就不缩。
3. **宽高收成偶数**：yuv420p 要求宽高都是偶数。

### 压缩 / 烧录：降帧 → 缩放 → 叠字幕

`FFmpegArgumentBuilder.filterChain`：横屏（含正方形）`scale=-2:N`，竖屏
`scale=N:-2`，`-2` 让另一边按比例走并收成偶数。

字幕在缩放**之后**画：按输出分辨率直接渲染，文字不经重采样，最清晰。版面不受影响
—— ASS 写的是 `PlayResY=1080` 加 `ScaledBorderAndShadow: yes`，libass 把这块虚拟
画布等比缩放到实际分辨率（`BurnInStyle.swift`）。

### 剪辑导出：画完再缩，放在滤镜图最后

画布、文字、形状、字幕全按工程尺寸画完，最后整幅 `scale=W:H,setsar=1`
（`VideoEditExportGraph` 末尾；W×H 由 `ResolutionLimit.cappedSize` 算出确切像素）。

1. **为什么不学压缩工具先缩再烧字幕**：剪辑导出的承诺是「预览看到什么、导出就是
   什么」。最后整幅缩小，成片严格等于全尺寸那一版的缩小版；先缩再烧，字幕就是在
   另一个分辨率下重新排的，得再证明一遍它和预览对得上。换来的清晰度在 720p 上差别
   很小。
2. **`setsar=1` 不能省**：取偶数会让宽高比差一丝（1000×562 → 854×480），scale 会
   改 SAR 去补（实测 1.000108），播放器照着它按非方形像素显示。
3. **画布本身不变，只降不升**：画布的固定比例都是 1080 级（`CanvasRatio.fixedSize`，
   16:9 就是 1920×1080）。想要「16:9 出 4K」是另一件事 —— 画布、文字、形状、变换、
   预渲染都得按新尺寸重建，没做。
4. 能选的档位：「跟随工程」加上 `ResolutionLimit.downscaleOptions` 给出的、短边比
   画布小的那几档。画布按**这次导出的**时间线算（选中导出 + Auto 画布时可能和整条
   时间线不同）。

## 二、面板上只放这条管线真消费的设置

显示一个管线不读的控件，就是给了用户一个不存在的控制承诺。剪辑导出这么错过两次：
分辨率 / 帧率上限（计划 §3.3），和「音频原样复制，不损失音质」
（[案例](../bugfixes/2026-09-24-export-panel-promised-audio-copy.md)）。

所以编码设置按**管线**声明自己消费什么（`EncodeSettingsSections.Pipeline`），不在视图
上一个控件一个控件地加开关：

| 管线 | 用在哪 | 视频 | 音频 | 输出（网页串流 / 元数据） |
| --- | --- | --- | --- | --- |
| `.sourceFile` | 压缩、烧录 | 编码器 + 质量 + 分辨率 / 帧率上限 | 原样复制 或 AAC 码率 | 有 |
| `.timeline` | 剪辑导出 | 编码器 + 质量（尺寸在面板外、帧率跟工程） | 只有 AAC 码率（声音要重新混音） | 有 |
| `.timelineAudioOnly` | 剪辑导出里只有声音（出 .m4a） | 无 | 只有 AAC 码率 | 无（那条管线不读） |

**给编码设置加新字段时**：先去 `FFmpegArgumentBuilder` 和 `VideoEditExportGraph` 各查一遍
读不读它，哪条管线不读，就不在那条管线的面板上显示。剪辑导出面板上别的行也是同一条
规则：只导音频时没有分辨率行，也没有「烧字幕」那一行。

## 三、剪辑导出面板：三行 + 高级

- **一眼看到的**：标题、导出至、分辨率（帧率只读，跟在同一行）；工程有字幕、且不是只导
  音频时，再加一个「烧不烧字幕」开关；有选中内容时顶上是「完整时间线 / 仅选中」。
- **「高级」默认收着**，展开 / 收起记住（`@AppStorage("videoEditExportAdvancedExpanded")`）。
  收着的那一行右边是**摘要**，内容就是高级里那些设置 —— 设置会被记住，改过的值藏在
  里面没人看得见是最坏的情况。摘要和里面显示的是同一批（只导音频时只剩码率）。
- **点「导出」直接开始，不再弹保存面板**：名字和位置已经摆在面板上了。回车 = 导出
  （`.keyboardShortcut(.defaultAction)`，输入框聚焦时也一样）；Esc = 关闭
  （`.onExitCommand`；`.cancelAction` 会被即时提示的守卫拦下，见
  [即时提示](instant-tooltips.md)）。
- 导出途中整张 Form 锁住：参数在开始那一刻就定了，途中改了也不作数。

## 四、文件名与导出位置

- **标题 → 文件名主干**只有一个函数：`ExportFileName.stem`（去首尾空白、`/` `:` 换成 `-`、
  剥掉用户顺手打进来的扩展名、去掉开头的点、什么都不剩就用默认标题）。扩展名不归用户
  填，灰字跟在输入框后面：`.mp4`，只导音频时 `.m4a`。
- **默认标题**：工程文件名；没存过的工程用第一段素材的名字。
- **改过的标题只在当前工程里记住**：按 `documentGeneration` 认，换工程就回到工程名；
  只放内存、不进工程文件（不是画面数据，不值得动格式版本）。和默认一样就不记，工程
  改名时标题才会跟着走。
- **导出位置**：记住的文件夹（全局一个，`UserDefaults` 的 `videoEditExportFolder`；App 没开
  沙盒，存路径就行）→ 工程文件旁边 → `~/Movies`。记住的文件夹不在了（删了、外接盘
  拔了）就当没记过。导出时用的那个文件夹就是下次的默认。
- **独立字幕文件**写进同一个文件夹，文件名跟标题走：`<标题>.<lang>.srt`，和视频同名，
  播放器能自动挂上。

## 五、撞名：先提示、再确认替换（视频和字幕文件同一条）

1. 目标已经有同名文件时，面板上先出一行橙色提示。**刚从这个面板导出去的那一份不算**
   —— 不然一导完就冒出「已存在」。
2. 点「导出」/「导出字幕文件」时，只要目标存在就先弹确认（取消 / 替换）—— 刚导出的
   那一份照样问，和系统保存面板一个行为。
3. 替换是原子的：视频走「workspace 里的临时文件 → `replaceItemAt`」（`VideoEditExporter`），
   字幕走「临时名 → 回读校验 → 原子替换」（`SubtitleExportPlanner.writeValidated`）。
   任何一步失败都不碰旧文件。
4. 字幕文件以前是撞名追加 `-2` / `-3`（计划第 13 节），重导几次就堆出一串、还和视频
   配不上对；2026-09-24 起改成和视频同一条规则。

## 六、记住与恢复默认

- 剪辑导出的编码设置**记住上次的**（`UserDefaults` 的 `videoEditExportSettings`，JSON）。
- **「恢复默认设置」只管高级区里的**；分辨率在面板外面、看得见，不动它。已经是默认时
  置灰，点了不弹确认。
- 分辨率也记住。记住的档位这块画布给不了（换到了更小的工程）就显示「跟随工程」——
  导出那边是同一个结果：档位不小于画布短边时 `cappedSize` 本来就不缩。

## 回归矩阵

| 检查 | 守什么 |
| --- | --- |
| `SrtFlowCoreChecks`（ffmpeg 参数构建一节） | 压缩 / 烧录：横屏、竖屏、正方形各自压哪一边，只降不升，宽高缺一个不缩 |
| `SrtFlowCoreChecks`（分辨率档位一节） | `cappedSize` 的确切像素（竖屏、奇怪比例取偶数）、`downscaleOptions` 给哪几档 |
| `SrtFlowCoreChecks`（标题 → 文件名主干一节） | `ExportFileName.stem` 的清理规则 |
| `SrtFlowCoreChecks`（字幕导出规划器一节） | 同名旧文件被整份原子替换、失败不碰已有文件 |
| `scripts/check-export-frame-rate.sh`（第三组） | 剪辑导出**真跑一遍**读成片尺寸：16:9 / 9:16 选 720p、跟随工程、档位不小于画布时不缩；奇怪比例下像素是方的（守 `setsar=1`） |

## 人工回归清单（自动化够不着，发版前实机过）

面板长什么样、控件对不对得上管线，要看真实窗口（[GUI 冒烟流程](../testing/gui-smoke-testing.md)）。

1. 收着的时候只看到：标题、导出至、分辨率（有字幕时加烧录开关）、「高级」和摘要。
2. 展开「高级」：视频 / 音频（**只有 AAC 码率**）/ 输出 / 字幕文件 / 恢复默认设置。
3. 只导音频：扩展名 `.m4a`，没有分辨率行、没有烧录行，「高级」里只剩音频，摘要只有码率。
4. 同名：提示条出现；点导出先问；「取消」不动旧文件；「替换」之后是新内容；刚导出的
   那一份不出提示条，但再点导出照样问。字幕文件同样走一遍。
5. 标题打 `L12/final:v2.mp4` → 文件名 `L12-final-v2.mp4`。
6. 回车导出、Esc 关闭（标题框聚焦时也一样）。
7. 恢复默认设置：改过才亮；点完摘要回到默认，分辨率不变。
8. 选 720p 真导一次：成片 1280×720、SAR 1:1。
9. 中文界面：整个面板和确认框都是中文（sheet 不继承应用内语言的坑，见
   [本地化](localization.md)）。
10. 压缩 / 烧录两个工具的设置页不受影响：分辨率、帧率、音频「原样复制」都还在。
