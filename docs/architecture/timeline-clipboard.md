# 时间线上的复制 / 剪切 / 粘贴

> 2026-09-26 用户拍板 + 实施。改时间线的拷贝、剪切、粘贴，右键菜单里的这三项，剪贴板的类型，或者
> 「粘到哪」的任何规则之前必读。拍过的板和理由见
> [方案](../plans/2026-09-26-timeline-clipboard-and-zoom.md)（C1–C9），这里只写长期约束。

## 一、能拷的和入口

| 能拷 | 不能单独拷 |
| --- | --- |
| 剪辑（视频 / 图片 / 声音）、文字和数字、形状、滤镜段、原文 / 译文两条轨上的字幕句 | 标记（跟着它所在的那段一起走）、转场（两边的段都被拷走时才跟着走） |

| 入口 | 走哪 |
| --- | --- |
| ⌘C / ⌘X / ⌘V、编辑菜单 | `AppDelegate` 的 `copy:` / `cut:` / `paste:`（**响应链的最末端**：输入框里的 ⌘C 还是复制文字，白捡的；自己监听按键在 ⌘V 上不成立 —— 编辑菜单的 Paste 亮着时，键盘等价符在本地监听之前就被它吃掉了，2026-09-21 实测）。亮灭由 `validateMenuItem` 说了算：拷贝 / 剪切看 `canCopySelection`，粘贴看剪贴板上有没有时间线内容或文件（**只看类型、不读内容**） |
| 右键菜单 | 五种块（剪辑、文字、形状、滤镜、字幕句）都有「剪切 / 拷贝 / 粘贴」；轨道空白处（标尺以外的行）有「粘贴」。菜单项是一个函数给的（`TimelineClipboardMenu`），**不是新的视图类型**：右键菜单的内容可能跟着块的 body 一起算，多一个视图类型就多一笔计数（[预览性能 ratchet](preview-perf-ratchet.md)） |

右键的那一块**在选中集合里**就作用于整个选择，不在就先单选它（`runClipboardCommand`）。右键菜单里的
「粘贴」不按剪贴板亮灭（算菜单内容时不去读剪贴板），剪贴板里没东西时点了响一声。

## 二、剪贴板：系统剪贴板、自己的类型、不写纯文本

- 类型 `com.srtflow.timeline-items`（`TimelineClipboard`），在 `packaging/Info.plist` 的
  `UTExportedTypeDeclarations` 里声明（`checks/exported-types-declared.sh` 钉着）。走系统剪贴板：
  **跨工程粘贴天然成立**。
- **不写纯文本**：写了的话复制一段剪辑会把用户剪贴板里的字换成一串 JSON，粘到别处是一坨乱码。
- **只有这一套**：2026-09-26 之前滤镜段有自己的剪贴板（`com.srtflow.filter-clip`），并进来删掉了。
  同一件事两份剪贴板，迟早有人读错（守卫钉着它不许回来）。
- 载荷（`TimelineClipboardPayload`）里每一样都是**完整的一份**，和存盘同一套编码；外加粘贴要用的
  「它原来在哪」：剪辑在哪条轨（主轨 / 上层轨的身份和第几条 / 音频轨的身份和第几条）、字幕句在哪条轨、
  藏没藏（旁表里的）。静帧还没转完（不存盘的临时状态）单独带着。载荷带版本号，比自己新的当没有。
- **拷的时候**就把「下一段没被一起拷走」那段的转场去掉（转场写在出场段身上，另一半不在它就不成立）。
- 链接开着时，拷视频连带它链接的音频（和 ⌫ 同一条链接语义）。

## 三、粘到哪

**落点**（`pasteTimelineItems`）：鼠标在时间线的**轨道区**里（滚动区里标尺以下，含右边、下边撑出来的空白）
就是鼠标那一刻，整批按两条边吸附（同拖文件，屏幕上 7pt；吸附关着不吸）；不在（预览、检查器、菜单栏上，
标尺上，轨道头那一列上）就是**播放头**，不吸。右键菜单的「粘贴」用右键**按下**的那一处（时间线的事件监视器
记下来，`TimelineContextClick`）。整批里最早的开头对齐落点，前后间隔不变。换算只走
`TimelineScrollGeometry.location(ofWindowPoint:in:)`（不许按坐标 hitTest 找滚动视图，
[案例](../bugfixes/2026-09-26-pinch-zoom-anchor-never-applied.md)）；行怎么排只有 `TimelineRowList` 一份。

**换身份**：每一样粘出来都是新身份（`ClipboardIdentity.renewed`：编码、换掉顶层的 `id`、再解回来）。
**别手写「除了 id 以外每个字段都照抄」**：`id` 是 `let`，手写迟早漏字段（分割那条路就漏过 `remoteKey` 和
`isHidden`，[案例](../bugfixes/2026-09-26-split-drops-hidden-and-library-key.md)）；编码里没有 `id` 键就拒绝粘，宁可粘不出来也不许出两个同身份的东西。链接组换新组号（粘出来的
一对彼此链接），只拷到组里一段时不留组号。

**各类落到哪**（`TimelinePaste`，纯值）：

| 类 | 规则 |
| --- | --- |
| 剪辑 | 按原来那条轨分组，**每组整组落在同一条轨上**。鼠标指着的轨放得下这一类（且这一类只有一组）就落那条；放不下这一类（视频指着音频轨）或按播放头粘，回原来那条轨（按身份找；藏着 / 找不到 —— 跨工程 —— 画面从主轨起、声音从头找）。**撞上了**：画面往上抬一轨、声音换一条放得下的，都满了新开一条；**不盖掉、不挤走**（用户选的 1A，同拖文件）。画面组从下往上落，**上面的组永远落在下面的组之上**；声音组各找一条、互不共用。藏起来的轨不上梯子。落到主轨以外的段去掉转场。磁吸开着时主轨照样自动合拢（`perform` 收尾的 `packMain`，同拖文件） |
| 文字 | 从鼠标指着的那一行（这一批只来自一行时）或原来那一行起往上找第一条空的；原来那一行在这个工程里没有（跨工程）就在最上面新开一行。收拢空行 |
| 滤镜段 | 从指着的那一层（单一来源时）或原来那一层起往上找空的；原来那一层不存在就落在空着的最低层（同按 `+`）。收拢空层 |
| 形状 | 只有一行、允许重叠：平移就完了 |
| 字幕句 | 鼠标指着哪条字幕轨就粘进哪条（这一批只来自一条轨时），否则回原来那条；允许和已有的句子重叠。藏着的照样藏着。原文轨还没有就建一条空的；没有原文轨时译文句也落进原文轨。粘进译文轨的句子来源记成重叠最多的那句原文、算「拆合过」（永远不自动更新，`SubtitleTrackEditing.insertCue(_:into:…)`） |

粘完：**一步撤销**（一次 `perform`；只粘了叠层类时不重建预览），**选中粘出来的东西**，播放头不动。
静帧还没转完的图片段照原图再转一次（登记进后台任务，切工程时能取消）。

**剪切** = 拷贝 + ⌫（`deleteSelected` 同一个入口：链接伙伴一起删、磁吸开着时主轨空档自动合拢、一步撤销）。

**Finder 复制的文件**（⌘V）同一个落点规则：鼠标在轨道区里就是鼠标那一处（左边缘对齐、指着的轨优先，同拖放），
否则播放头（[拖文件进轨道](../plans/2026-09-22-media-file-drop.md)）。时间线内容优先于文件（它是本 App 的私有类型，
意图更明确；两者不会同时在剪贴板上 —— 写的时候先 `clearContents()`）。

## 四、回归

| 守什么 | 在哪 |
| --- | --- |
| 拿什么（转场只在两边都被拿走时带、字幕句的轨和藏没藏、载荷往返与版本）、换身份（除了 id 每个字段照抄）、落到哪（撞上往上抬、几组保住上下关系、声音各找一条、藏着的轨跳过、链接组换新号、文字 / 滤镜 / 字幕句 / 形状各自的规则、负的落点当 0） | `scripts/check-timeline-clipboard.sh` |
| 往字幕轨里加一句现成的（字和样式带着、旁表记法） | `swift run --arch arm64 SrtFlowCoreChecks`（`SubtitleTrackChecks`） |
| 编辑菜单三项、剪贴板只有一套且不写纯文本、五种块和轨道空白处的右键菜单、右键按在哪有人记、落点鼠标优先（含 Finder 文件）、标尺不算轨道 | `checks/timeline-clipboard-wiring.sh` |
| 窗口里的一点 → 哪一刻、哪一行，落点、选中（真窗口） | 进程内冒烟的 `copy` / `cut` / `paste` 步骤（[GUI 冒烟流程](../testing/gui-smoke-testing.md)「四之六」；⌘C ⌘V 这类菜单快捷键在驱动里按不动，右键菜单也驱不动，所以直接调工程的动作、`paste` 按右键菜单那条路走） |

**人工回归清单**（发版前实机过一遍）：

- [ ] 选中一段主轨素材 ⌘C，鼠标停在主轨后面的空白处 ⌘V：粘在鼠标那一刻（左边缘在指针处）、选中它；鼠标停在已有
      素材上 ⌘V：往上抬一条轨，不盖掉、不挤走。
- [ ] 鼠标移到预览上再 ⌘V：落在播放头；点编辑菜单 ▸ 粘贴：也落在播放头。
- [ ] 框选一片（剪辑 + 文字 + 字幕句）⌘C ⌘V：整片的前后间隔、上下关系都不变；⌘Z 一步全撤。
- [ ] ⌘X 一段主轨素材（磁吸开着）：后面的合拢；再 ⌘V：粘出来。
- [ ] 右键一段没选中的块 ▸ 拷贝：只拷它；右键选中集合里的一块 ▸ 拷贝：拷整个选择。在轨道空白处右键 ▸ 粘贴：落在
      右键的那一处。剪贴板空的时候点「粘贴」：响一声。
- [ ] 在字幕 / 工程名 / 文字内容的输入框里 ⌘C ⌘V：还是复制粘贴文字，不动时间线。
- [ ] 一个工程里 ⌘C，打开另一个工程 ⌘V：粘得出来、素材能播。
- [ ] 在 Finder 里 ⌘C 一个视频，鼠标停在某条轨的空白处 ⌘V：落在鼠标那儿、那条轨。
- [ ] 切到简体中文（系统英文时）：右键菜单是「剪切 / 拷贝 / 粘贴」。
