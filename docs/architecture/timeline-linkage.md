# 联动：压在主轨块上的东西跟着它的画面走

> 2026-10-02 起。用户要「和剪映一样：打开之后，只要和主轨上的块在一个范围内的，任何东西都链接在一起，删除一起删、移动一起移」，
> 细节由我按用户体验拍（[方案](../plans/2026-10-02-timeline-linkage.md) 记着每条怎么定的、为什么）。本文是长期约束：
> 规矩、落在哪、守卫、人工回归。代码：`Sources/SrtFlow/VideoEditTimelineLinkage.swift`（规则）、
> `VideoEditTimelineLinkageLanding.swift`（撞上了往哪让）、`VideoEditProject.perform` / `liveApply`（钩子）、
> `VideoEditProject+Selection.swift`（拖动计划要的名单）。
> 相关：[拖动手势](timeline-drag-gestures.md)、[剪辑页上记住的开关](editor-remembered-toggles.md)、[AI 接口（MCP）](ai-control-mcp.md)。

## 一、一句话

**「联动」开关（工具栏那个链子，`EditorToggles.linkage`，默认开）开着时：时间线上任何不在主轨上的东西，跟着它底下压着的主轨
画面走 —— 画面挪到哪它挪到哪，画面被删了它也删。** 显式的链接组（视频 + 分离出来的音频、录屏画面 + 麦克风，`linkGroup`）照旧，
而且更强（拉开了也跟）。单向：主轨带别的，别的不带主轨。

## 二、规矩（`TimelineLinkage`）

| # | 规矩 | 代码 |
| --- | --- | --- |
| 1 | **跟着画面走，不跟块的 id。** 每样东西看自己底下压着主轨的哪些画面（哪个素材的第几秒）；一次改动之后那些画面挪到哪，它就挪到哪。分割、`cut_speech`、定格插入切出来的新 id 照样认（同一个素材、接着的源时间）；**同 id 的段永远优先**（粘贴 / 复制出来的同素材新段不算画面挪过去了；重链接换了路径也不算） | `Ledger`：改之前每段主轨的「时间线 ↔ 源时间」账，改之后按同 id、再按新出来的同素材段找画面去了哪 |
| 2 | **完全落在一段主轨块里的**：删它就删、挪它就挪。挪多少按它底下**最早还在**的那一截画面算，和那截画面的相对位置不变 | `Ledger.outcome`：`inside` |
| 3 | **跨两段的**（配乐铺整片、一句字幕跨过接缝）：底下的画面**全部**挪同一个量才跟，否则不动；画面**全没了**才删 | `Ledger.outcome`：非 `inside` 时所有幸存画面的位移一致才 `.move` |
| 4 | **真删才连带删。** ⌫、AI 的 `delete_items` / `cut_speech` 传 `deletesContent: true`；裁切、变速、定格、拖动、AI 的 edit_clip 让画面没了的，东西**留在原地不动**（裁切是边拖边看的探索动作，拖过去一句字幕就没了太吓人；留在原地一眼能看见、按 ⌫ 就删） | `perform(deletesContent:)`；`liveApply` 永远 false |
| 5 | **这次操作自己碰过的东西不再碰**（值和改之前不一样就算碰过）：拖动的成员已经按实际落点平过了、链接组的伙伴已经一起裁了，别再按联动挪一次 | `follow` 只看 `before == after` 的那些 |
| 6 | **撞上了让开**，让的永远是这次挪过的那个：上层轨的段往上抬一轨、音频轨的段另找一条，都放不下新开一条（同拖文件 / 粘贴的梯子；隐藏的轨不上梯子）；文字往上找空行、滤镜往上找空层；字幕句和形状允许重叠 | `TimelineLinkageLanding.settle` |
| 7 | **一处收口。** 规则只在 `TimelineLinkage.follow`，钩在 `perform` / `liveApply` 收尾（磁吸合拢之后、补色之前）：删、拖、裁、变速、加转场、定格、粘贴插进主轨、拖文件插进主轨、AI 的 ripple、磁吸拨开合拢，全都自动对；不存任何状态、不抬工程格式 | 守卫 `checks/timeline-drag-wiring/linkage.sh` |
| 8 | **拖动中**：被拖的主轨块压着的东西是这一轮拖动的成员（`TimelineLinkage.attachments`：底下压着的主轨块全在要动的名单里才算），实时跟着画、**没有障碍**（不许反过来挡住主轨块）、不当吸附参考点；磁吸下按宿主实际落到哪再平一次（`ClipDragPlan.Member.host` → `realignCompanions`）。别的主轨块合拢是松手时的事，它们压着的东西也松手时跟 | `VideoEditProject.linkedAttachments` / `ClipDragPlan.adding(attachments:)` |
| 9 | **哪些算「任何东西」**：上层视频轨、音频轨（含分离出来的音频）、文字、形状（含盖一块）、滤镜段、字幕句（原文 / 译文两条轨各按自己的时间判）。标尺标记不算（它钉在时间线的绝对时刻）；段上的标记、转场、关键帧本来就长在段上 | `follow` 里五类各扫一遍 |
| 10 | **开关关着**：以上一样都不发生，只有显式的链接组（老行为） | `perform` / `liveApply` / `linkedAttachments` 都先看 `linkageEnabled` |

### 几个具体场景（也是自检的用例）

| 场景 | 结果 |
| --- | --- |
| 磁吸开，删主轨第 2 段，它上面有两句字幕、一段音效 | 两句字幕和音效一起删；第 3 段起的主轨块前移，它们上面的字幕 / 文字 / 音效跟着前移同样多 |
| 一句字幕跨过第 1、2 段的接缝，删第 1 段 | 字幕不删，跟着第 2 段前移（夹在 0） |
| 配乐从 0 铺到尾，删中间一段 / 把第 1 段拖到最后 | 配乐不动、不删 |
| 配乐从 0 铺到尾，删第 1 段 | 后面全部前移同样多 → 配乐跟着（夹在 0），不删 |
| 磁吸开，拖第 3 段到第 1 段前面 | 第 3 段上的字幕实时跟着去前面；第 1、2 段后移，它们上面的东西松手时跟着后移 |
| `cut_speech` 剪掉一段里的三处停顿 | 停顿上的东西删掉，停顿之后的字幕 / 文字跟着画面前移 |
| 磁吸开，裁掉第 1 段的头 2 秒 | 第 1 段里的字幕跟着画面前移 2 秒；被裁掉那 2 秒上的字幕留在原地（不删） |
| 变速 2 倍 | 段里的东西各自跟着自己那一帧到一半处（时长不变） |
| 定格插入 | 定格点之后的字幕 / 文字跟着后移一个定格时长（联动关着时照旧「定格只动它所在的那一条轨」） |
| 分割一段、改转场类型、改音量 | 画面没挪，什么都不动 |
| 主轨块拖去上层轨 | 它还在（同 id），压在它上面的东西按它的新位置跟；它原来的邻居合拢，邻居上的东西跟着 |

## 三、给 AI 的那一面

- `get_timeline` 的结果带 `linkage: true/false`；`delete_items` / `cut_speech` / `edit_clip` / `cut_to_beat` 的结果里带
  `linkage: {moved, deleted, note}`（什么都没动就不带，`AILinkageReport`）。
- 工具说明：`delete_items`、`freeze_frame`（`MCPTimelineTools.swift`）、`cut_speech`（`MCPSmartEditTools.swift`）写明开关开着时别的轨跟着动；
  `cut_speech` 的 `next_step` 按开关分两种说法（关着才提醒重新生成字幕）。
- AI 的工具按用户的开关走，和手动一个口径；`cut_speech` 剪掉的那几块永远是真删（`deletesContent: true`），它本来就不管开关带着链接的声音剪。

## 四、已知不足

- 跨段的东西只按「全部画面挪同一个量」判：一句字幕跨过接缝、前一段被拖去别处时，它留在原地（没有正确答案）。
- 裁切 / 变速让画面没了的东西留在原地（规矩 4），一眼看得见但要自己删。
- 变速只挪起点、不缩时长：段里 2 秒的字幕在 2 倍速下还是 2 秒。
- 拖动中只有被拖那块压着的东西实时跟；邻居合拢带动的要松手才跟（和主轨块自己的表现一致）。
- 「联动设置」按类型勾选（剪映有）不做；要的时候再加。

## 五、守卫

- `scripts/check-timeline-snap.sh` 第 1f 组（`checks/TimelineSnap/Linkage.swift`）：上面那张表逐条 —— 删中间 / 删第一段 / 磁吸关着删、
  真删与否、主轨没挪什么都不碰、换位、操作自己动过的不再碰、主轨块拖去上层轨、分割不动、cut_speech 的切删（新 id 认得出、剪掉那一截上的删）、
  裁头（画面前移、被裁掉那一截上的留在原地）、变速、定格、粘贴的同素材新段不算、撞上让开（段换轨、文字换行、滤镜换层、没撞不碰）、
  拖动计划的名单与成员（没有障碍、带宿主、不重复）。**反向验证**做过：拿掉「同 id 优先」、「跨段要一致」、「真删才删」、撞上让开，各红。
- `checks/timeline-drag-wiring/linkage.sh`（`checks/timeline-drag-wiring.sh` 第 12 节）：`perform` / `liveApply` 收尾调 `follow`、位置在 packMain
  之后、画面账只有一份、真删的三个入口传 `deletesContent: true` 且只有它们传、三个拖动计划带上压着的东西、`realignCompanions` 按宿主平、
  `get_timeline` 报开关、工具说明写了联动；第 12e 节：整份换回（AI 的「撤销这一轮」，`restoreTimeline`）不过磁吸、不过联动
  （[案例](../bugfixes/2026-10-02-undo-round-repacks-v1.md)）。
- 默认值：`checks/timeline-drag-wiring/toggles.sh` 第 11a 节、`scripts/check-timeline-zoom.sh` 第 4 节（`TogglesChecks.swift`）。

## 六、人工回归（改这些代码后过一遍）

- 开关开着、磁吸开着：拖一段带字幕和音效的主轨块到别的位置 —— 字幕和音效实时跟着块走，松手后邻居合拢、邻居上的字幕跟着归位；⌘Z 一步全回。
- 删一段主轨：它上面的字幕 / 文字 / 音效没了，后面的全部前移、字幕仍贴着说的话；配乐不动。
- 裁一段主轨的头：拖把手时段里的字幕实时前移；被裁掉那一截上的字幕留在原地。
- `cut_speech` 剪停顿之后字幕仍贴着说的话（`get_job` / 结果里有 `linkage`）。
- 开关关着：以上一样都不跟（只有分离出来的音频跟视频）。
- 磁吸关着、开关开着：删一段留着缝，只删它上面的东西，后面不动。
