# 声音场景：喇叭 / 室内 / 室外

> 2026-09-24 落地。改 `VideoEditSoundScene*.swift`、`VideoEditAudioMix.swift` 里挂了场景的那一支、
> 电平表 tap（`VideoEditAudioMeter.swift`）、检查器的声音那一块（`VideoEditInspector+Sound.swift`）之前必读。
> 拍过的板与探针见 [声音场景方案](../plans/2026-09-24-sound-scenes.md)；同一条声音链上的另外几环见
> [声音：音量与渐入渐出](audio-fades.md)、[推子与电平表](audio-mixer.md)、[成片的声音](export-audio-mixdown.md)。

## 一、模型

- `EditClip.soundScene: SoundScene?`：`kind`（九种，分三组）+ `amount`（强度，0 = 原声）+ `first` /
  `second`（场景自己的两个旋钮，都是 0…1）。喇叭类的旋钮是「失真」「音质」，空间类是「空间大小」「距离」
  （`SoundSceneKind.controls`）。
- 九种：**喇叭**（电话、扩音器、收音机）、**室内**（房间、浴室、大厅）、**室外**（空旷室外、森林、山谷回声）。
  海边不做（没有海浪声就和室外一样；环境声是音效库的事）。
- 换种类：强度留着，两个旋钮回到新场景的默认值（`SoundScene.switching`）。「重置」：种类不变、三个数回默认。
- 读盘和写入都走 `sanitized`（NaN 回默认、越界夹进 0…1）。**认不出的种类整个不认**（更新的版本加的），
  当作没有场景，别的设置照常读回来。
- 编辑入口只有三个（`TimelineState.setSoundSceneKind` / `setSoundSceneValue` / `resetSoundScene`），
  单选、框选批量都走它们；没有声音的段跳过。
- 分割：两半各带同一个场景（`split` 里显式抄；右半是按 init 重建的，**新字段不抄就丢**）。
  分离音频：场景跟着声音走（`detachedAudio`）。
- 工程格式 **v20**，按需写键（见 [工程文件](video-edit-project-file.md)）。

## 二、声音怎么算（预览和成片是同一份）

**效果跑在每条合成音轨已有的 tap 里**（`SceneTrackRenderer`，VideoEditSoundSceneTrack.swift），用
`AudioUnitRender` 驱动 macOS 自带的效果单元（AUNBandEQ / AUDistortion / AUReverb2 / AUDelay，
配方在 VideoEditSoundSceneRecipe.swift）。成片离线读同一份合成时同样调 tap（`TapContext.standaloneTap`）——
「只做一遍」就是这么成立的。2026-09-24 探针：离线读和实时播放逐位相同、分块大小不影响结果、延迟为 0。

九条不许改的：

1. **挂了场景的合成音轨，段的增益在 tap 里乘，AVFoundation 只放总推子**（常数）。AVFoundation 在空档里
   一直沿用空档开头那一刻的音量，余音会被下一段的钉点压掉或放大（探针实测）。这种轨上：
   段增益（音量 / 曲线 × 渐变）→ 效果 → 轨道推子；AVFoundation 乘总推子。没挂场景的轨照旧。
2. **效果排在段增益之后、轨道推子之前**：人声淡出时余音照常散完；拉推子连余音一起变小（Logic 的
   region → insert → fader）。自检第 9 组「淡出之后余音照常散」钉着。
3. **每段一条效果链**，余音各自散：段结束之后它的链继续吃静音、吐余音，直到余音那么长的时间过去；紧跟着
   的下一段进它自己的链，两边相加。所以**分割不改声音**（混响是线性的，自检钉着）。
4. **余音越过段尾要有「载体」**：一条合成音轨最后一段之后 tap 就不再被调、`insertEmptyTimeRange` 补的
   空段会被静默丢掉。挂了场景的合成音轨最后一段后面垫一截**同一个素材文件**（格式天然一致），垫固定的
   `SceneRecipe.maximumTail`（6 秒，到工程结尾为止 —— 最后一段的余音不把成片拉长）。tap 按段路由，段外的
   输入一律当静音，垫的内容从来听不见（`SceneTailCarrier`）。
5. 因为第 4 条，**有没有场景是合成结构**（加 / 去掉场景会重建一次预览），**种类和旋钮只进 audioMix**
   （拖滑杆不闪画面）。`differsOnlyInAudioMix` 按这个口径抹平。
6. **时间跳了就复位效果链**（seek、从头播）：拿到源音频之后先比时间戳，对不上就 `AudioUnitReset`，旧的余音
   不许拖进新位置。**时间无效的回调（开播第一拍、暂停 / seek 之后的空转）输出静音、不碰效果链** ——
   空转也跑的话余音会被耗掉。
7. **旋钮一律自己换算成参数，不载入单元的出厂预设**：AUReverb2 载入预设后 Dry/Wet 读回来是 0.5（满量程 100）。
8. **喇叭类先削波、最后限带**：反过来的话削波会在限好的频带外重新长出高次谐波（自检量到过：6kHz 以上几乎
   没削掉）。
9. **响度补偿用同一串处理量出来**（`SceneLoudness`：48kHz 立体声、−20 dBFS RMS 的语音样噪声、量后一半），
   按种类和两个旋钮（取到 1%）缓存。**串了两个单元的链会把输入那一块写成输出**：量输入能量、加原声那一份
   都必须在渲染**之前**（第一版补偿全是 0 dB 就是这么错的）。喇叭类的削波跟着电平走（素材越响失真越重，
   真喇叭也这样），补偿按常见人声电平量，响的素材会偏一点。

**「强度」是在场景输出之外、和原声交叉混的**：输出 = (1 − 强度) × 原声 + 强度 × 补偿 × 场景。各单元自己的
干湿比是「场景里听到的那一份」（喇叭类全湿，空间类按「距离」混一部分直达声）。

**电平表看的是 tap 处理完的声音**：挂了场景的轨，tap 输出已经乘过段增益和轨道推子，所以给电平表的增益表是
空的（= 1），总表再乘总推子。

**波形照旧画「原声 × 增益」**，不画效果（画效果就得逐段重算，丢掉「一个文件读一次」的前提）；块上的小图标
（喇叭 / 房子 / 树，按组）表示挂了场景。

## 三、界面

- 检查器「音量」下面一块（`SoundSceneControls`）：按三组分节的下拉菜单，选了场景才出现「强度」和两个旋钮
  （都显示百分比）以及「重置」。下拉是离散控件，直接 perform 一步；滑杆 liveApply + 松手 endLiveEdit，
  拖动中 `previewAudioLive` 换一份 audioMix，当场听得见。
- 框选多段时同一块批量套用（有声音的段），各段种类不一样时下拉显示「多个值」、不给滑杆。
- 提示文案说清楚「只能加空间感，去不掉素材里本来的回声」。

## 四、回归

| 检查 | 守什么 |
| --- | --- |
| `scripts/check-project-file.sh`（第 29 组） | 默认值、换种类留强度、夹紧、只动有声音的段、重置 / 去掉；拖旋钮和换种类只换 audioMix、去掉场景要重建；分割两半都带、分离音频带走；按需写键、v20、往返保真；认不出的种类当作没有、越界夹回 |
| `scripts/check-audio-fade.sh`（第 9 组） | 真实 PCM：电话削掉 6kHz 以上（宽频素材、四阶量）；大厅的余音越过段尾且慢慢散（最后一段后面的载体）；淡出之后余音照常散（效果在段增益之后）；强度 0 = 原声；九个场景默认值下和原声差不过 3 dB；成片 = 预览；带电平表的 tap 和成片的 tap 一样、电平表看得见余音；分割前后一样 |

**反向验证（2026-09-24）**：去掉载体 → 余音三条红（段尾后静音）；成片不挂场景 tap → 电话那条红；
`split` 不抄场景 → 第 29 组「分割后两半是同一个场景」红（开发时就是这条先红的）。
