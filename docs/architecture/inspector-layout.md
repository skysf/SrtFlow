# 检查器的排版：一条固定的窄栏

> 2026-09-24 起。往检查器（`VideoEditInspector*.swift`）里加任何一行之前必读。
> 案例：[选了声音场景却看不见选的是哪个](../bugfixes/2026-09-24-sound-scene-row-widens-inspector.md)。

## 约束

1. **一行的最小宽度不许超过检查器那条窄栏**（去掉两边 14pt 边距约 220pt）。检查器的 `ScrollView`
   只纵向滚、横向只裁：哪一行要得比栏宽，整列跟着被撑宽，**右边一截全看不见**（菜单上的字、「Mute」、
   滑杆后面的数值），而且症状落在别的行上，很难一眼看出是哪一行惹的。
2. **菜单型 Picker 不许 `.fixedSize()`**：它的理想宽度按最长的选项算，锁死就不能收缩。守卫
   `checks/inspector-fits-width.sh` 钉着（只管 Picker；标签固定又很短的小菜单，比如裁切比例的
   None / Custom，锁住没关系）。
3. **标题 + 选项多、名字长的下拉**：标题单独一行，下拉铺满下一行（「转场」「声音场景」都是这样）；
   标题和控件挤一行的，控件必须能收缩（动画那两行的 Picker 就没锁宽度）。
4. 固定宽度只给短而定长的东西：标签列（`frame(width: 68)`）、数值（`frame(width: 40)`）。

## 回归

| 检查 | 守什么 |
| --- | --- |
| `checks/inspector-fits-width.sh` | 检查器文件里的 Picker 修饰器链上没有 `.fixedSize()`（反向验证 2026-09-24：放回去就红） |

**人工回归**（自动化够不着「放不放得下」，改检查器之后实机看一眼）：

- [ ] 英文界面（英文比中文长）下，选中一段带声音、挂了场景的剪辑：「Mute」、音量的 dB、下拉上的选中项、
      每个滑杆后面的数值都完整可见；往下滚到 Split / Delete，右边没有被裁掉的字。
