# 画面上的形状：线条 / 长方形 / 正方形 / 圆 / 圆弧，和它们的入场 / 出场动画

> 盖一块（模糊 / 马赛克）也是 `ShapeKind` 的两种，但它们不画东西，规矩全在 [盖一块](cover-blur-mosaic.md)。
> 这份管「画出来的」那几种。

## 一、种类和几何（`VideoEditShapeModels.swift`）

| 种类 | 外接框 | 能不能实心 | 转不转 |
| --- | --- | --- | --- |
| `line` | 宽 = 长度、高 0 | 不能（永远是线） | `rotationDegrees` ±90° |
| `rectangle` | 宽 × 高（画面的比例） | 能（`isFilled`） | 不转 |
| `square` | 边长 = 宽 × 画面**宽**（任何画幅里都是正的），高恒等于宽 | 能 | 不转 |
| `circle`（2026-10-03） | 直径 = 宽 × 画面宽，同正方形 | 能 | 不转 |
| `arc`（2026-10-03） | 同圆 | **不能**（永远是一条线） | `rotationDegrees` = 从 12 点钟方向顺时针转过多少开始，`arcSweep` = 顺时针扫过多少度（1…359，默认 270） |

- 「按宽取边长、高恒等于宽」只问 `ShapeKind.keepsSquare`（正方形、圆、圆弧）；新建时的默认大小只问 `ShapeKind.defaultSize`
  （检查器「加形状」和 AI 的 `set_shape` 同一份）。
- 「画成实心」只问 `drawsFilled`（线条、圆弧永远不是），预览和导出都问它。
- 线宽按 1080 高的画面算，只问 `ShapeAnnotation.strokeWidth(in:)`（`lineWidth × 画面高 / 1080`），描边**全在框内**：长方形往里收半个线宽，
  圆和圆弧的半径也减半个线宽，线条的圆线头在长度以内（可见长度就是 `width`）—— 选中框、可点范围和画出来的东西是同一个框。

## 二、怎么画：只有 `ShapeOutline` 一份（所有种类）

`VideoEditShapeOutline.swift` 的 `ShapeOutline.drawing(for:size:strokeWidth:state:)` 给出一块形状**这一刻**画成什么：一条 `CGPath`
（在自己的框里：左上原点、y 向下、框从 (0,0) 起）、涂满还是描边、线头、只露出哪一块（`reveal`）、整体透明度。动画状态（下一节）也在这里落到路径上。
三个用它的地方各自只管上色：

| 谁 | 怎么上色 |
| --- | --- |
| 预览：`ShapePreviewDrawing.view`（`ShapeOverlayCanvas` 调；是函数不是视图类型，不多一份性能计数） | `Path(cgPath)` 的 `fill` / `stroke`，`reveal` 用 `.mask`，透明度 `.opacity` |
| 导出：`ShapePNGRenderer.image` / `.render`（整幅透明图，导出叠在画面上） | 平移到框的左上角 `addPath`；`reveal` 用 `clip`，透明度 `setAlpha` |
| AI 的「看」：`AIFrameComposer` | 直接用导出那张图 |

`checks/project-file-wiring.sh` 钉着三处都调它；`scripts/check-shape-render.sh` 把预览那个画法离屏渲一张，和导出那张逐像素比。
2026-10-03 之前只有圆和圆弧走这里，线条和长方形预览、导出各画一份 —— 导出的线两头各比预览长半个线宽
（[案例](../bugfixes/2026-10-03-exported-lines-longer-than-preview.md)）。

- y 向下的坐标里角度变大 = 画面上**顺时针**；12 点钟是 -90°。`CGPath.addArc(… clockwise: false)` 就是角度变大的方向 ——
  SwiftUI 和翻转过的 CG 上下文都是 y 向下，所以两边画出来一样（这一条写反了，圆弧会往逆时针走：自检钉着 1:30 有、6 点和 9 点没有）。
- 线头：线条、圆、圆弧是圆头（`.round`），描边居中在「半径 − 半个线宽」上；长方形、正方形是平头尖角（`.butt` + `.miter`），整个描完时闭合。
- **还什么都没露出来时给空路径，不许用「裁到一块空区域」表达**：CoreGraphics 拿空路径 `clip` 等于没裁，导出会把整块画出来，而预览的 `mask`
  是全遮住 —— 两边对不上（写这一节时自检当场撞出来的）。

## 三、入场 / 出场动画（2026-10-03）

南极工程的报告：「图形没有入场、出场动画，只能突然出现、突然消失」。用户点了「形状入场、出场动画」，细节我定的（理由见第四节）。

**模型**（`VideoEditShapeAnimation.swift`）：`ShapeAnnotation.animation` = 入场、出场各一种效果 + 一个时长（默认 0.6 秒，0.1…5）。
效果四种，和文字动画**同名、同曲线**（`TextEasing`）：

| 效果 | 入场 | 出场 |
| --- | --- | --- |
| `fade` 淡入淡出 | 不透明度 easeOutCubic | easeInCubic（东西该被抽走，不是慢慢停住） |
| `pop` 弹性缩放 | 从 0.79 倍弹到 1（easeOutBack，冲过头约 1.1 再回来），同时淡入 | easeInCubic 直接收回 0.79 倍、淡出 |
| `wipe` 擦除 | 从左往右扫出来（线性） | 倒着收回去 |
| `draw` 画出来 | 顺着笔顺描出来（线性）：线从左端（转过角度后的那一端）起、长方形从左上角顺时针、圆从 12 点钟顺时针、圆弧从它的起点；**实心的**顺着同一个方向露出来：长方形从左往右、圆从 12 点钟顺时针扫一圈 | 倒着收回去 |

- **出场是入场倒着放**，和文字动画一样（同一个名字在文字和形状上做同一件事）。
- 时长夹紧和文字、声音、画面渐变共用 `FadeWindow.clamped`：入场 + 出场比这一块还长时按比例同时收；存的是用户的意图，夹紧在读的时候做。
  检查器当场说一句「两边已经按比例收短了」。
- 缩放绕框的中心、**只缩几何、不缩线宽**（预览和导出都缩路径，不缩画布 —— 两边各缩各的画布会在线宽上对不上）。
- 盖一块（模糊 / 马赛克）没有动画（`ShapeAnimator` 对它永远不动，AI 给了也不收）。

**求值**：`ShapeAnimator.state(for:at:)` 是纯值，时刻**先经 `TextAnimator.quantize` 钉到工程帧的网格上**（预览、导出、AI 的「看」同一把尺子），
入场和出场不会重叠，三段式：入场 / 中间（不动）/ 出场。

**导出**（`VideoEditShapeOverlayExport.swift`）：和文字同一个切法 —— 没有动画的整段一张图（`shape0.png`，和以前一样）；有动画的只逐帧渲
入场和出场那两截（`shape0-in_%05d.png` / `shape0-out_%05d.png`，末尾多渲一帧），中间一张图。三种片段怎么进滤镜图只有
`OverlayExportFile.append` 一份（`VideoEditOverlayExportFile.swift`，2026-10-03 从文字那边抽出来，文字和形状共用）；叠放次序：先形状、后文字。

**格式**：`animation` 按需写键（没设动画的不落），设了就是 **v31** 数据 —— 只认 v30 的旧版读进来当没有，随手存一下就把动画抹掉了
（[工程文件](video-edit-project-file.md)）。

## 四、拍过的板

### 圆和圆弧（2026-10-03，用户点了「圆形、圆弧形状」，细节我定的）

| 板 | 为什么 |
| --- | --- |
| 圆像正方形一样按宽取直径、永远是圆的；不另做椭圆 | 南极工程要的是 HUD 圆环；椭圆需要的时候再加一个种类，现在的长方形 / 正方形也是这么分的 |
| 圆弧用「起点 + 扫过」而不是「起点 + 终点」两个角 | 扫过多少度和起点无关，转起点（以后做动画）时不用两个数一起动；`rotationDegrees` 本来就有，线条用它表示角度 |
| 圆弧永远是线、不能实心 | 实心的圆弧是扇形，是另一种东西；要扇形时再加 |
| 起点收进 (-180°, 180°]（检查器「起始角」滑杆 ±180，AI 给的角度同样收） | 和文字的旋转、检查器的角度框同一个口径 |
| 工程格式抬到 v30 | 旧版宽容解码把不认识的种类退成长方形，存回去圆就成了方框（见 [工程文件](video-edit-project-file.md)） |

### 入场 / 出场动画（2026-10-03，用户点了「形状入场、出场动画」，细节我定的）

| 板 | 为什么 |
| --- | --- |
| 只收四种：淡入淡出、弹性缩放、擦除、画出来 | 报告要的是「别突然出现、突然消失」，片头 HUD 圆环要的是「画出来」；文字的上浮、逐字、打字机、模糊、对焦对一块形状没有意义或者和这四种重复 |
| 名字和曲线照抄文字动画，出场是入场倒着放 | 同一个名字在文字和形状上做同一件事；AI 和用户都只用学一次 |
| 没有强调（呼吸）、没有强度旋钮 | 质感来自曲线，旋钮摊开只会调出难看的结果（文字那边的同一条理由）；以后真有人要再加 |
| 实心的「画出来」顺着同一个方向露出来，不画一圈边再填色 | 实心形状没有边；画一圈同色边再填，半透明的颜色在重叠处会变深 |
| 「画出来」和「擦除」用线性 | 进度是几何量，加缓动会让扫过的速度忽快忽慢（文字擦除的同一条理由） |
| 缩放只缩几何不缩线宽 | 一块形状弹进来时线宽跟着变粗变细像在闪；只缩几何时两边也好对账 |
| 导出切段和文字共用一份接法（`OverlayExportFile`） | 两份接法会在边界条件上分叉（序列末尾多一帧、`-itsoffset`） |
| 工程格式抬到 v31 | 旧版读不认识的键当没有，存回去动画就没了 |

## 五、AI：`set_shape`

`kind` 多了 `circle` / `arc`，`sweep`（圆弧扫过多少度）；`rotation` 对线条是角度（±90，夹紧）、对圆弧是起点（收进 ±180）；`filled` 对长方形、
正方形、圆有效。结果和 `get_timeline` 里圆弧带 `sweep` 和 `rotation`。
入场 / 出场：`animation_in` / `animation_out`（`none` / `fade` / `pop` / `wipe` / `draw`，词表 `MCPVocabulary.shapeAnimations` 和
`ShapeAnimationKind` 对账）、`animation_in_duration` / `animation_out_duration`（默认 0.6，夹在 0.1…5），参数名和 `set_text` 一样；
只给一侧时另一侧不动；盖一块不收；结果里带设了的 `animation_in` / `animation_out`。规则在 `AIShapeChange`（纯值，`checks/MCP/ShapeChecks.swift`）。

## 六、守卫

- `scripts/check-shape-render.sh`（`check-all` 第 5 组）：
  - 预览 = 导出：`ShapePreviewDrawing` 离屏渲一张、`ShapePNGRenderer` 一张，白色形状铺在黑底上逐像素比（最亮的一点差 ≤ 3、墨迹外框差 ≤ 1.5 像素、
    重合 ≥ 0.97、平均差 ≤ 0.08），五种形状 × 描边 / 实心 × 不动 / 画到一半 / 擦除 / 缩放 / 半透明，外加「画了 0 / 擦了 0」两边都空。
    黑底不是装饰：`ImageRenderer` 渲透明底时，内容什么都没画就把上一张图原样还回来。
  - 真导出抽帧（30fps，白色圆环 0.5 秒起、2 秒长，入场画出来 0.8 秒、出场淡出 0.6 秒）：入场画到一半时 3 点亮、9 点黑；中间一整圈；
    出场淡到一半只剩一成左右的亮；段外全黑；只逐帧渲入场 / 出场那两截、中间一张图；没有动画的照旧一张 `shape0.png`。
  - 反向验证：导出的线改回线头在外 → 1 条红（外框差 4 像素）；预览不裁 `reveal` → 12 条红；导出不切段 → 5 条红。
- `scripts/check-mcp.sh` 的 `ShapeChecks`：set_shape 读圆 / 圆弧、夹紧、实心规矩、动画参数、回报；**真像素**（`ShapePNGRenderer` 渲 200×200）：
  圆一圈都有、里面空、框角空；圆弧从 12 点扫 90° 盖住 1:30、不盖 6 点和 9 点；起点转 180° 从 6 点开始。反向验证：`clockwise` 写反 → 3 条红。
- `scripts/check-project-file.sh` 第 43 组：v30 判据、只有圆弧写 `arcSweep`、往返、缺键读作 270°、圆的高跟着宽。
  第 44 组：动画按需写键、v31、往返、宽容解码；求值的三段式、曲线、按比例收、盖一块不动；`ShapeOutline` 的笔顺、线头在长度以内、
  实心的露出方向、擦除、缩放中心、什么都没露出来时是空路径。
- `checks/project-file-wiring.sh`：预览、导出都经 `ShapeOutline.drawing`；预览、导出、AI 的「看」都按钉到帧上的时刻问 `ShapeAnimator`；
  导出图经 `ShapeOverlayExport` 和 `OverlayExportFile.append`。
