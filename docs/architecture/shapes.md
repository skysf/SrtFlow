# 画面上的形状：线条 / 长方形 / 正方形 / 圆 / 圆弧

> 盖一块（模糊 / 马赛克）也是 `ShapeKind` 的两种，但它们不画东西，规矩全在 [盖一块](cover-blur-mosaic.md)。
> 这份管「画出来的」那几种。

## 一、种类和几何（`VideoEditShapeModels.swift`）

| 种类 | 外接框 | 能不能实心 | 转不转 |
| --- | --- | --- | --- |
| `line` | 宽 = 长度、高 0 | 不能（永远是线） | `rotationDegrees` ±90° |
| `rectangle` | 宽 × 高（画面的比例） | 能（`isFilled`） | 不转 |
| `square` | 边长 = 宽 × 画面**宽**（任何画幅里都是正的），高恒等于宽 | 能 | 不转 |
| `circle`（2026-10-03） | 直径 = 宽 × 画面宽，同正方形 | 能 | 不转 |
| `arc`（2026-10-03） | 同圆 | **不能**（永远是一条线） | `rotationDegrees` = 从 12 点钟方向顺时针转过多少开始，`arcSweep` = 顺时针扫过多少度（1…359，默认 270） |

- 「按宽取边长、高恒等于宽」只问 `ShapeKind.keepsSquare`（正方形、圆、圆弧）；新建时的默认大小只问 `ShapeKind.defaultSize`
  （检查器「加形状」和 AI 的 `set_shape` 同一份）。
- 「画成实心」只问 `drawsFilled`（线条、圆弧永远不是），预览和导出都问它。
- 线宽按 1080 高的画面算（`lineWidth × 画面高 / 1080`），描边**全在框内**：长方形用 `strokeBorder` / 往里收半个线宽，圆和圆弧的半径
  也减半个线宽 —— 选中框、可点范围和画出来的东西是同一个框。

## 二、圆和圆弧怎么画：只有 `ShapeOutline` 一份

`VideoEditShapeOutline.swift`：圆、圆弧在自己外接框里（左上原点、y 向下、框从 (0,0) 起）的那条 `CGPath`。
预览（`ShapeOverlayCanvas`：`Path(cgPath)` 上色）和导出（`ShapePNGRenderer`：平移到框的左上角 `addPath` 上色；AI 的「看」也用这张 PNG）
拿的是**同一条路径**，圆弧从哪儿起、往哪边扫只在这里算一次（`checks/project-file-wiring.sh` 钉着两边都调它）。

- y 向下的坐标里角度变大 = 画面上**顺时针**；12 点钟是 -90°。`CGPath.addArc(… clockwise: false)` 就是角度变大的方向 ——
  SwiftUI 和翻转过的 CG 上下文都是 y 向下，所以两边画出来一样（这一条写反了，圆弧会往逆时针走：自检钉着 1:30 有、6 点和 9 点没有）。
- 线头是圆的（`lineCap: .round`），描边居中在「半径 − 半个线宽」上。

## 三、拍过的板（2026-10-03，用户点了「圆形、圆弧形状」，细节我定的）

| 板 | 为什么 |
| --- | --- |
| 圆像正方形一样按宽取直径、永远是圆的；不另做椭圆 | 南极工程要的是 HUD 圆环；椭圆需要的时候再加一个种类，现在的长方形 / 正方形也是这么分的 |
| 圆弧用「起点 + 扫过」而不是「起点 + 终点」两个角 | 扫过多少度和起点无关，转起点（以后做动画）时不用两个数一起动；`rotationDegrees` 本来就有，线条用它表示角度 |
| 圆弧永远是线、不能实心 | 实心的圆弧是扇形，是另一种东西；要扇形时再加 |
| 起点收进 (-180°, 180°]（检查器「起始角」滑杆 ±180，AI 给的角度同样收） | 和文字的旋转、检查器的角度框同一个口径 |
| 工程格式抬到 v30 | 旧版宽容解码把不认识的种类退成长方形，存回去圆就成了方框（见 [工程文件](video-edit-project-file.md)） |

## 四、AI：`set_shape`

`kind` 多了 `circle` / `arc`，`sweep`（圆弧扫过多少度）；`rotation` 对线条是角度（±90，夹紧）、对圆弧是起点（收进 ±180）；`filled` 对长方形、
正方形、圆有效。结果和 `get_timeline` 里圆弧带 `sweep` 和 `rotation`。规则在 `AIShapeChange`（纯值，`checks/MCP/ShapeChecks.swift`）。

## 五、守卫

- `scripts/check-mcp.sh` 的 `ShapeChecks`：set_shape 读圆 / 圆弧、夹紧、实心规矩、回报；**真像素**（`ShapePNGRenderer` 渲 200×200）：
  圆一圈都有、里面空、框角空；圆弧从 12 点扫 90° 盖住 1:30、不盖 6 点和 9 点；起点转 180° 从 6 点开始。反向验证：`clockwise` 写反 → 3 条红。
- `scripts/check-project-file.sh` 第 43 组：v30 判据、只有圆弧写 `arcSweep`、往返、缺键读作 270°、圆的高跟着宽。
- `checks/project-file-wiring.sh`：预览和导出都经 `ShapeOutline.path`。
