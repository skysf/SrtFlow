# 2026-09-27 AI 翻译按旧的原文语言去翻，等下载时又一声不吭

> 开发中（PR #81，AI 接口第一块）用户在 Claude Code 里实测发现的，没合并、没发布。长期约束写进了
> [AI 接口（MCP）](../architecture/ai-control-mcp.md) 第四节第 7 条。

## 症状

用户在 Claude Code 里说「我要中文 + 韩文」。字幕原来是英文，Claude 先用 `edit_subtitles` 把原文轨整轨
改写成中文，再调 `translate_subtitles` 翻成韩文。接着：

1. SrtFlow 窗口里弹出 macOS 的「下载翻译语言」框，列的是 **English (US) + Korean** —— 系统按「英文→韩文」
   去翻，而原文此刻已经是中文，翻出来的韩文会是错的。
2. Claude 那边只看到任务进度一直是 0，说「可能在下载，再等一下」；弹框在 SrtFlow 窗口里，用户在看对话，
   两边都在等。用户：「应该引导下用户，去点击下载，不然用户会根据提示一直在等，以为软件有问题」。
3. 用户点了下载之后，系统设置里韩语已经下到七成，SrtFlow 里那个框的进度条还停在开头，
   「好像卡住了一样」。

## 根因

1. **原文语言信的是旧记录**：`translate_subtitles` 拿 `subtitleCompanion.sourceLanguage` 当原文语言。
   它是生成字幕那一刻记下的（英文）。`edit_subtitles` 只改字，不会、也不该去猜语言，于是记录过期了。
   面板上的「翻译」按钮同样读这条记录，但界面上人不会把原文整轨改写成另一种语言，AI 会。
2. **下载只能由用户点**：苹果的 Translation 框架规定，缺语言时由系统弹框、用户点「下载」，
   **没有静默下载的接口**（`prepareTranslation()` 也只是提前弹这个框）。框挂在 SrtFlow 的主窗口上，
   而 AI 接口平时特意不抢前台 —— 框在后面，谁也看不见；任务只知道进度是 0，说不出「在等人」。
3. **系统框的进度条不可信**：它是系统翻译服务画的、嵌在 SrtFlow 里，App 不在最前面时常常不刷新。

## 修复

1. **原文语言先按字判断**（`AITextLanguage`，系统自带的 NaturalLanguage，整轨一起判、置信度 ≥ 0.5 才认），
   判不出来才退回工程里记的；AI 也可以显式传 `source_language`。翻译成功后，工程里记的语言跟着更新
   （`applyTranslations` 本来就把这次用的源语言写回去）。
2. **翻之前先问这一对语言装没装**（`LanguageAvailability`）。装好了直接翻，不会弹框。要下载时：
   - 把 SrtFlow 激活、主窗口摆到最前面，让系统的框露出来。这是 AI 接口里唯一故意抢前台的地方：得让用户点得着。
   - 工具结果和 `get_job` 里带 `waiting_for_user`，写明「请用户在 SrtFlow 的框里对每种语言点 Download，
     只需一次」。给 AI 的总说明里加一条：见到 `waiting_for_user` 就马上转告用户，不许闷着头等。
   - SrtFlow 顶上的提示条同步显示这句话。
3. **自己盯真实状态**（`AIDownloadWatch`）：每两秒问一次系统装好了没。下载中提示「真实进度看系统设置 ›
   通用 › 语言与地区 › 翻译语言」，下完了提示「框还开着的话点 Done」；翻出第一句、或者任务结束，提示就收掉。
4. 「生成字幕后顺便翻译」那一路同样处理：进到翻译那一步才知道原文语言，那时再查、再引导。

## 验证

- `scripts/check-mcp.sh`：`checks/MCP/LanguageChecks.swift` 用真的 NaturalLanguage 判中文（zh-Hans）、
  英文（en）、韩文（ko），空行判不出来（退回旧记录）。同一个脚本扫描：`translationSource` 里按字判断排在
  旧记录前面，而且 `translate_subtitles` 确实走它。
- **反向验证**：把 `translationSource` 里「按字判断」和「用旧记录」两行对调，扫描红在「没有先按字判断原文
  语言（判断在第 5 行、旧记录在第 4 行）」；恢复后绿。MCP 自检 196 项全过。
- 真机：用户按修好的测试版重跑「中文 + 韩文」（待测：这次系统应当要中文 + 韩文两种语言，提示条和 Claude
  都会说去点下载；下完之后翻出来的是韩文）。

## 教训 / 防回归

- **从工程里读出来的「这是什么语言」只是当时的记录。** AI 会整轨改写内容，人不会；给 AI 用的入口，
  凡是依赖「内容是什么」的，按内容现判，别信旧标签。
- **要人动手的地方，AI 接口必须说出来。** 进度 0% 不是信息；「在等你点下载」才是。系统弹框、权限申请、
  任何只有用户能点的东西，都要走 `waiting_for_user` + 提示条，并把窗口摆到用户看得见的地方。
- **别拿系统的界面当状态来源。** 系统框的进度条会停；自己去问系统（`LanguageAvailability`）才是真的。
