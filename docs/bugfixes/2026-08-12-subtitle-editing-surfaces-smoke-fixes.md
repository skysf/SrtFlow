# 2026-08-12 字幕三入口首测：检查器被挤出窗口、新行拿不到光标

字幕编辑三入口（时间线双击 / 预览双击 / 右栏字幕表）落地当天的 GUI 冒烟里抓到的两个
bug。两个都在**合入之前**发现并修掉，但结论可复用，所以照规矩留案例。

## 一、字幕表做成并排第三栏时，检查器被挤出窗口右边界

### 症状

`HSplitView { 预览 | 字幕表 | 检查器 }`：字幕表一出现，检查器整条往右顶出窗口 ——
「输出尺寸」「Export…」都被窗口右边缘切掉，宽度只剩约 198pt（它的 `minWidth` 是 252）。
更糟的是**底下的时间线工具栏也跟着被切**，看起来像整个编辑器变宽了。

### 根因

`HSplitView` 分地时按每一栏的 **ideal** 走，而且**宁可让排在最后的那一栏溢出，
也不会把前面几栏压回各自的下限**。预览那一栏钉着 `idealWidth: 700` 又拿着
`layoutPriority(1)`，700 + 300 + 290 超过可用宽度，被牺牲的就是最后的检查器。

试过三种都没用（记下来省得再走一遍）：

1. 开着字幕表时把预览的 `idealWidth` 降到 430 —— 分栏器记着既有的分割位置，不动；
2. 套一层 `HSplitView { 预览 | 字幕表 }` 再和检查器并排 —— 里层那一组的 ideal
   变成两栏之和，外层照着它分地，一样溢出；
3. 给检查器更高的 `layoutPriority` —— 它改成优先拿**自己的 max**（360），
   左边那组反而被压到下限以下，溢出方向换了个人而已。

### 修复

结构上取消第三栏：**字幕表和检查器共用右栏**，字幕表盖在检查器上面，✕ 回到检查器
（2026-08-12 用户拍板的形态，也正好绕开分栏器）。分栏器从此永远只有两块，
开关字幕表不动任何分割线。见 `VideoEditView.swift` 的右栏 `Group { if … }`。

## 二、按 + 新建一行后光标不在新行上，接着打的字变成快捷键

### 症状

字幕表按 +：新行确实建出来了（选中、高亮、显示占位文字），但光标不在它的输入框里。
用户以为可以直接打字，实际上每个按键都落到编辑器的全局快捷键上 ——
空格开始播放、V 切换轨道眼睛、M 打标记、A/B 换工具。**用户以为在打字，其实在改工程。**

### 根因

焦点是在**行**里给的：`onAppear` 中写自己的 `@FocusState`。

- 当拍写没用：那一刻输入框还没进响应链；
- 隔一拍（`DispatchQueue.main.async` / `asyncAfter`）也没用：新建 cue 会让面板重建，
  闭包里捕获的是**已经作废的那份行视图**，写进去的 `@FocusState` 没人消费。

### 修复

**焦点归面板持有**：`@FocusState private var focusedField: SubtitleFieldFocus?` 放在
`VideoEditSubtitlePanel` 上（面板一直在），行里拿 `FocusState.Binding`；`addCue()`
建完 cue 后隔一拍把 `focusedField` 指到新行的原文格。见
`VideoEditSubtitleCueRow.swift` 顶部的 `SubtitleFieldFocus` 说明。

顺带一条产品判断：原文轨隐藏时 + 直接置灰 —— 合同只往原文轨写，那一格输入框根本
不存在，聚焦必然失败，又会掉回「按键变快捷键」这个坑（2026-08-12 复审 P2）。

## 验证

GUI 冒烟（真实窗口 + 合成点击/按键）：右栏切换不再影响检查器与时间线工具栏；
按 + → 直接输入 "NEW LINE TYPED" → 回车，文字落进新行，预览叠层同步更新，
⌘Z 一步退文字、再一步退新建。`scripts/check-all.sh` 17 项全过。

## 教训 / 防回归

1. **`HSplitView` 不保护最后一栏。** 要加一栏之前先问「这一栏能不能和现有的某一栏
   共用位置」；真要并排，得接受最后一栏可能溢出，并且知道 ideal / priority 都救不了。
2. **临时视图（`ForEach`/`LazyVStack` 里的行）不能给自己上焦点。** 焦点状态要放在
   生命周期长的那一层，用 `FocusState.Binding` 往下传。
3. **「聚焦失败」在这个 App 里不是小事**：编辑器装着单键快捷键，焦点一丢，
   用户的每次敲键都变成一次工程修改。新增任何「自动聚焦」的入口都要实测一遍
   「建出来 → 直接打字」。
4. 长期约束已落到
   [subtitle-track-visibility-and-layout.md](../architecture/subtitle-track-visibility-and-layout.md)
   的「编辑入口」一节（第 6、9 条）。
