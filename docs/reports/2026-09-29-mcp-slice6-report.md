# AI 接口（MCP）第六块实施报告：fal.ai 生成

> 2026-09-29。方案 [第 14–19、36、42、52、57、58 条](../plans/2026-09-27-mcp.md)，长期约束 [fal.ai 生成](../architecture/fal-generation.md)。
> 分支 `feat/fal-generation`（按用户说的「每块单独一个分支和 PR」，从 main 切出）。

## 做了什么

- **用户的两句话改了预设**（第 57 条）：「视频只用 `minimax/h3-max/` 这个系列，能生成音乐的、音效的也都加上」「要最新的模型，太老的不要」。
  于是模型表是七种事各一个、各取 fal 目录里当天**最新**的：图 Seedream 5.0 Flash、文 / 图生视频 MiniMax H3 Max、旁白 Eleven v4、克隆 Zonos2、音乐 Eleven Music v2.5、
  音效 Sonilo 1.1；理由、单价和更新办法在架构文档第二节，`scripts/fal-models/refresh.sh` 能重下接口定义、按上架日期列各类最新的、核对价格页。
- **Key**：设置 → AI 里填、存系统钥匙串、能删（`FalKeyStore` / `FalKeyCache` / `FalSettingsRow`）；**每日上限**（默认 $10，能改，不设单次上限）、今天已花、每种事的模型（端点号 + 单价，能改）也在那里。
- **`generate_media`**（图 / 文生视频 / 图生视频 / 音乐 / 音效）：回任务号，`get_job` 等，停止 / `cancel_job` 能取消（替 fal 也取消）；成品放用户的 `SrtFlow/生成`；不改工程。
  **超额度、价格不明先在顶上的提示条上问**（允许 / 先不要 / 停止，不弹模态框，不管这一轮什么状态都摆出来）。
- **清单跟着 Key 走**（方案第 36 条）：没配 Key 就没有这个工具，总说明里也不提；App 在 Key 添加 / 删除和启动时写一个只有提供方名字的小文件，小程序每回一次清单都重读，
  老一代客户端收 `list_changed`，新一代靠一分钟的缓存。
- **配旁白三档**：fal > SrtFlow 自己的 > macOS；额度不够 / Key 读不出来自动退档并说为什么；fal 报的词时间读得出来就出字幕；`clone_from` 克隆（只有 fal 能做）。
- 请求体**逐条对着 fal 公开的接口定义快照验**（`checks/Fal/schemas/`）：没有 Key 也能逮住「第一次拿真 Key 才露馅」的那类错。

## 撞上的事（没有一件进了产物）

1. **取消发不出去**：Task 被取消时直接 `await cancel(...)`，URLSession 的 async 接口一看见取消就不发请求，fal 那边没被取消。假协议自检里「fal 被要求取消了」得 0（该是 1）才发现；
   改成在不继承取消的 Task 里发。
2. **`LAContext` 拦不住老式钥匙串的授权框**：想把弃用的 `kSecUseAuthenticationUIFail` 换成 `LAContext.interactionNotAllowed`，探针里读别的签名建的项，进程卡在框上等人点；老常量才拦得住，留着并写明原因。
3. **冒烟弹了一次钥匙串授权框**：第一次冒烟用 `security add-generic-password -T` 预置 Key，ad-hoc 签名对不上 `-T`，App 读时弹了 macOS 的框、任务永远 running。框已关掉、项已删。
   由此两处改进：任务在等 macOS 授权框时给 AI 一句 `waiting_for_user`（不然 AI 对着「没动静」的任务干等）；冒烟改成让 App 自己建这一项（`SRTFLOW_SMOKE_FAL_KEY`，只在指到本机假 fal 时生效）。
4. **冒烟把两个测试文件放进了用户的 `~/Downloads/SrtFlow/`**（第三个场景没先 `open_folder`）：已删；两个场景脚本现在都先开临时文件夹，文档里写明。
5. **H3 Max 的声音**：以为 `add_clips` 会把视频自带的声音另放一条音频轨，冒烟里看时间线只有 V1 一个片段 —— 声音随片段一起播。文档、结果里给 AI 的 `note` 都改了（要压低或静音）。
6. **提示条只挂在剪辑页里**：`generate_media` 不切栏目，用户在别的栏目时问花钱的问题看不见、任务永远等。拍测试 App 的窗口截图才发现（窗口停在压缩页，没有提示条）；
   现在问之前先把剪辑页摆出来（后台模式也一样），守卫钉着先后；重新拍了一张：剪辑页顶上三行问题 + 「先不要 / 允许 / 停止」三个按钮排得下。
7. 接口定义的细节网页摘要不写（`prompt_expansion_mode` 必填、图生视频没有 `aspect_ratio`）：fal 公开的 OpenAPI 接口直接给准确的定义（字段、取值、范围、必填），以后先读它、快照进仓库。

## 没有对真 fal 验过（第一次拿真 Key 时逐条看，也在架构文档第十节）

Eleven v4 的 `timestamps` 元素长什么样（定义里元素是空的，读不出来就没有词时间）、每个端点的真实产出、中文旁白的音色好不好听、Zonos2 读中文和 16 kHz 参考音频的效果、
H3 Max 促销价 9-30 结束后的价、估算和账单的差。**设置里 fal 一节的排版只在第一屏看过**（窗口要滚下去，System Events 那次读不到窗口，没自动化）。

## 等用户拍板

1. **钥匙串的授权框**：ad-hoc 签名的测试版每个新版本第一次读 Key 弹一次（点「始终允许」），发布给别人的 Developer ID 版只弹一次。要免弹只能把项的访问控制放宽成「任何应用」（等于普通文件的安全性）或存文件。现在按方案存钥匙串、默认访问控制。
2. **音乐 / 音效 / 图片 / 旁白 / 克隆的默认模型**是我按「最新 + 能控制 + 单价固定」挑的（音乐没选 MiniMax Music 3：歌词必填、没有纯音乐开关；图片没选 GPT Image 2.5：按 token 计价估不准）。设置里都能改。
3. 全清单说明总长 70,377 / 72,000 字符，余量不到 2 千：以后再加工具要先把别处写短。
