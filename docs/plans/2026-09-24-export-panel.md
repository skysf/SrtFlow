# 导出面板改版：三行 + 高级

长期约束（只放管线真消费的设置、文件名、撞名、记住与恢复默认、人工回归清单）写在
[导出设置](../architecture/export-settings.md)；本文记目标和拍过的板。

## 一、目标（用户原话）

> 这个界面里展示的东西太多了，我想把这里简化下，用户在这里首先看到的是「标题」「导出至」
> 还有分辨率这三个，剩下的全部折叠到 Advance 里面……别的因为基本也不会调整，就放到
> Advance 里面好了。

参考图是 CapCut 导出面板的「标题 / 导出至」两行。改版前的面板一打开就是编码器、CRF
滑杆、Preset、音频、网页串流、元数据六组设置，要滚一屏才看得到导出按钮；名字和位置反而
不在面板上，要点「Export…」之后在系统保存面板里定。

## 二、拍过的板（2026-09-24）

先讨论、列问题带推荐，用户逐条回复（多数是「按你的建议来」）。推翻前先读理由。

| 决定 | 口径 | 理由 |
| --- | --- | --- |
| 分辨率 | **能选，只降不升**：「跟随工程（W×H）」+ 比画布短边小的标准档；在滤镜图最后整幅缩小 | 用户选的（三选一里的 B）。只读不够用（发给别人要小文件）；往上升要按新尺寸重建整张画布，是另一件事 |
| 档位按什么算 | **短边**：9:16 选 720p 是 720×1280；选项里直接写出实际像素 | 「720p」这种叫法说的就是短边；写出像素，竖屏和奇怪比例都不会误会 |
| 缩放放在哪 | 滤镜图**最后**，字幕、文字都画完再缩 | 成片严格等于全尺寸那一版的缩小版，和预览一致；压缩工具先缩再烧是为了字幕更清晰，这里不值得再证明一遍版面对账 |
| 帧率 | 只读，跟在分辨率同一行 | 帧率是工程的唯一事实来源（[工程帧率](../architecture/project-frame-rate.md)），面板上不给第二个入口 |
| 保存面板 | **不再弹**，点「导出」直接开始 | 名字和位置已经在面板上了；再弹一次就是两处定同一件事 |
| 默认标题 | 工程名；没存过的工程用第一段素材名；去掉原来的 `_edit` 后缀 | 截图里的「L12」就是工程名；后缀是给保存面板防撞名的，现在有专门的撞名规则 |
| 扩展名 | 不让用户填，灰字跟在后面；只导音频时自动 `.m4a` | 格式由管线决定，填了也改变不了容器 |
| 默认位置 | 记住上次导出的文件夹（全局一个）；第一次用放工程文件旁边，没存过就 `~/Movies` | 最常见的是「一直导到同一个地方」；第一次放工程旁边，文件不会散落 |
| 撞名 | 输入时就出一行提示；点导出再确认一次替换 | 和系统保存面板同一个行为，不会静默覆盖；自动续号（`L12 2.mp4`）重导几次就堆一串 |
| 「完整时间线 / 仅选中」 | 留在顶上（只在有选中时出现） | 每次导出都要想的决定，平时又看不见，不占地方 |
| 烧字幕开关 | 留在外面；独立字幕文件收进高级 | 烧不烧直接改变成片画面；独立文件是另一个产物，用得少 |
| 独立字幕文件 | 不再另选文件夹，写进「导出至」，文件名跟标题走（`<标题>.<lang>.srt`）；撞名同视频的规则；仍然可以单独导（不绑在导出视频上） | 和视频同名同目录，播放器能自动挂上；以前追加 `-2`，重导几次就配不上对 |
| 高级区的摘要 | 收着时右边一行显示当前设置 | 设置会被记住，改过的值藏着没人看见是最坏的情况 |
| 记住设置 | 编码设置和分辨率都记住上次的 | 用户说「可以记住上次的设置」 |
| 恢复默认设置 | 放在高级区底部；只管高级里的，不动分辨率；已是默认时置灰；不弹确认 | 用户要求加「万一设错了能重置」；分辨率在外面看得见，自己就能改回「跟随工程」 |
| 回车 / Esc | 回车 = 导出；Esc = 关闭 | 和系统对话框一致 |
| 改动范围 | 只动剪辑导出面板；压缩 / 烧录两个工具的设置页原样 | 那两个工具里编码参数本身就是主角（用户同意） |
| 顺带的老问题 | 压缩 / 烧录的分辨率上限按高度算、竖屏被缩小 —— 一起修（同一个 PR，单独 commit） | 用户：「顺带发现的老问题，一起修」 |

## 三、做的时候又发现的

都按「顺带发现、一起修、各自一个 commit 和案例」处理：

- 面板上「音频原样复制，不损失音质」对剪辑导出是假话 —— 那条管线每次都重新编码成 AAC
  （[案例](../bugfixes/2026-09-24-export-panel-promised-audio-copy.md)）。高级里改成只有
  AAC 码率；只导音频时只剩这一项。
- 本地化守卫不扫 `LabeledContent`，录屏提示里的「File」一直没翻译
  （[案例](../bugfixes/2026-09-24-labeledcontent-missing-from-localization-guard.md)）。
- 中文界面冒烟时发现所有 sheet / popover 都不继承应用内语言
  （[案例](../bugfixes/2026-09-24-sheets-ignore-in-app-language.md)）。

## 四、分刀（一个 PR，多个 commit）

1. 压缩 / 烧录的分辨率上限按短边算（竖屏不再被缩小）。
2. 剪辑导出的滤镜图支持缩小到选定分辨率（先没有界面，默认值不变）。
3. sheet / popover 套上应用内语言。
4. 导出面板本身：三行 + 高级、记住与恢复默认、撞名确认、字幕文件跟标题和位置走。
5. GUI 冒烟流程补这次用到的手段。

## 五、验收

自动检查见 [导出设置](../architecture/export-settings.md) 的回归矩阵；真实窗口按那里的人工
回归清单走了一遍（英文、中文各一遍；720p 真导出核成片 1280×720、SAR 1:1、字幕烧在对的
位置）。
