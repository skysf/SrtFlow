## 一、剪辑风格怎么用

- **AI 自己挑**（第 39 条）：剪整片之前先调只读工具 `recipes` 看有哪几套、每套「什么时候用」，按用户的目的挑一套，
  **用一句话告诉用户挑了哪套**（「这条按带货的路子剪：前 3 秒放成品，30 秒以内」），再按它读全文、照着剪。
- **用户的话永远优先**：用户说了时长、平台、风格、要不要音乐，就照用户的；剪辑风格只补用户没说的部分。
- **卡是起点，不是死规矩**：素材不够（没有人声、没有产品特写、音乐库里没有合适的配乐）时按卡上写的退路走，
  并在做完时告诉用户缺了什么。
- **用户自己的剪辑风格**（第 41 条）：用户说「把刚才这套存成剪辑风格，叫 XX」，AI 用 `save_recipe` 按同样的格式写一份；
  和内置同名就是用户改过的那一版。

## 二、所有剪辑风格共用的规矩

1. **先摸清素材再动手**：`open_folder` → `look files`（一次看全部）或 `look shots=true`（长视频分镜头）→ 有人说话的
   `transcribe` → `listen`（音量、静音段）。挑镜头看画面，不看文件名猜。
2. **先问平台**（第 26 条）：用户没说发哪儿就问一次。抖音 / TikTok / 小红书 / Reels / Shorts → 9:16；YouTube / B 站 → 16:9。
3. **9:16 的安全区**：平台的按钮和文案会盖住画面**上 10%、下 20%、右 12%**。大字、字幕、要看清的东西都放在这之外
   （文字的 y 在 0.12–0.75 之间，x 在 0.08–0.85 之间）。
4. **字**：一屏只有一个重点；同一条片子最多两种字体；每行短（中文 ≤ 8 个字，英文 ≤ 5 个词）；字不压在人脸和主体上
   （`set_text` 回的 `block` 和 `look` 对一下）。
5. **声音**：有人声时配乐比人声低约 15 dB（`listen` 量，`edit_clip volume_db` 调）；没有人声时配乐约 −18 dB；
   开头 0.5 秒内要有声音，结尾配乐淡出（`fade_out`）不硬切。
6. **不编造**：数字、评价、学员人数、价格、链接一律只用素材和用户给的（第 27 条：课程推广不写价格，结尾用
   「点主页链接了解」这类通用话）。
7. **导出前自检**：每张卡最后一节的清单逐条过；`look` 时间线上几个关键时刻（开头、每段第一帧、结尾），`listen` 整条时间线。
8. **做完告诉用户**：用了哪套、多长、画幅、导出在哪；用了音乐库的音乐给出署名句（`music_credits`）。

## 三、五张卡

### 1. 带货 / 课程推广（`product-promo`）

**什么时候用**：卖东西、推广课程或服务、App 演示、直播切片、开箱种草。**卖的是课**时看本节最后「卖的是课」。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 短视频平台 9:16；YouTube 16:9 |
| 时长 | 15–30 秒（短视频）；最长 60 秒 |
| 结构（30 秒版） | **0–3 秒 钩子**：结果先行 —— 最好看的成品、前后对比、最惊人的数字，或者一句戳痛点的话；同时出一行大字。不许用 logo、慢淡入开场。<br>**3–8 秒 痛点 / 场景**：为什么需要它。<br>**8–22 秒 卖点**：2–3 个卖点，每个 = 一个镜头 + 一句话 + 一行关键词大字；有数字的用数字滚动。<br>**22–27 秒 证据**：成果、前后对比、真实评价（素材里没有就跳过，不编）。<br>**最后 3–5 秒 号召**：「点主页链接了解」这类通用话，最后一帧停住至少 1.5 秒 |
| 镜头 | 1–3 秒一个，平均约 2 秒；**每 2–3 秒画面必须变一次**（换镜头、画面放大入场、出字）。口播先 `cut_speech`：去口头禅、停顿缩到 0.15–0.25 秒 |
| 转场 | 硬切为主；换段落偶尔 `pushLeft` / `pushUp`（0.3 秒以内）；揭晓成品可以 `whiteFade` 闪一下（0.15 秒） |
| 画面动画 | 关键产品镜头 `entrance: pop` 或 `zoom`（0.3 秒）；静止的产品图用 `set_keyframes` 慢慢放大（大小 1 → 1.08） |
| 滤镜 | 产品、室内、干净：`coldWhite`；生活场景：`warmSun`。强度 0.5–0.7，整条片子一个 |
| 文字 | 关键词大字：中文 `PingFang SC` 粗体，英文 `Avenir Next` 粗体（或 `Futura`）；9:16 字号 110–140；白字 + 深色描边，或纯色底框（`background_color`）；`animation_in: pop` 或 `cascade`；放在上三分之一（字幕在下）。数字用数字滚动（0 → 目标值，1 秒） |
| 字幕 | 开；逐词高亮（第 ④ 刀做完后）；9:16 放在下安全区之上 |
| 配乐 | 轻快、明亮：`find_audio` 搜 bright / hopeful / electronic。**音乐库现在缺轻快的**：找不到合适的就不放，告诉用户可以给一首自己的 |
| 配音 | 有口播用原声。纯产品画面才配旁白：`zh_female_lively` / `en_female_lively`，语速 1.1× |
| 自检 | 前 3 秒 `look`：有大字、有主体；每 3 秒画面有变化；人声清楚、音乐不盖人声；时长在范围内；最后一帧有号召、停够 1.5 秒 |

**卖的是课**（课程推广，第 27 条）：

- 先 `transcribe` 全部课，挑三样：**学完能做出来的东西**（成品、效果对比、最惊艳的一步操作）、**老师说得最有力的一两句**
  （「学完你能……」「这一招……」）、**课程覆盖了什么**（按章节归成 3 个模块）。
- 结构：钩子（成品或最有力的那句）→ 这门课教什么（3 个模块，各一个画面 + 一行字）→ 老师是谁（一句话，可省）→ 号召。
- 录屏类画面要看得清：`edit_clip` 放大到操作的那一块（`x / y / scale`），不要整屏缩在 9:16 里。
- 带 `WaterMark` 的素材照常用，除非用户说了不用。不写价格、不编学员人数和评分。

### 2. 电影开头（`cinematic-opening`）

**什么时候用**：短片、旅行片的开场，预告片感，作品集开头，品牌故事开头。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 16:9；上下加电影遮幅：两个实心黑色长方形（`set_shape` rectangle、`filled`、`#000000`、宽 1、高 0.128，y 分别是 0.064 和 0.936），从头到尾都在，画面就是 2.39:1 |
| 时长 | 30–90 秒 |
| 结构 | **0–5 秒 冷开场**：黑场里先出声音（环境声或音乐的第一个音），画面 `blackFade` 渐入；第一个镜头是远景（交代在哪）。<br>**5–25 秒 铺陈**：慢，长镜头 3–6 秒一个，从远到近（远景 → 中景 → 特写），音乐慢慢起。<br>**片名**：落在音乐的一个重音上，居中，停 3–4 秒。<br>**25–45 秒 加速**：镜头变短（1.5–2.5 秒），跟着拍子切（`cut_to_beat`，拍子不清楚就手剪），情绪往上走。<br>**收尾**：最后一个镜头停久一点，`blackFade` 出 |
| 镜头 | 铺陈段 3–6 秒，加速段 1.5–2.5 秒；动作要完整（不在动作中间切） |
| 转场 | `crossFade`（0.8–1.5 秒）和 `blackFade`（段落之间）；不用推移、擦除 |
| 画面动画 | 静止或很稳的镜头用 `set_keyframes` 慢推（大小 1 → 1.06–1.1，整个镜头的时长） |
| 滤镜 | 大片感 `tealOrange`，怀旧 `fadedFilm`；强度 0.6–0.8 |
| 文字 | 片名：英文 `Didot` / `Bodoni 72` / `Optima` 大写、字距拉宽（`letter_spacing` 20–40）；中文 `Songti SC`（宋体）；字号 90–120；`animation_in: focus`（1–1.5 秒），`animation_out: fade`；不压在遮幅上。<br>地名、年份：小字 `Avenir Next` / `PingFang SC` 常规体 36–44，左下角，`fade`，4 秒。除此之外不加字 |
| 字幕 | 默认关（没有对白）；有对白才开，白字小字、不要底框 |
| 配乐 | 宏大、动情：`find_audio` 搜 epic / trailer / opening / orchestral / emotional。从片头就起，片名落在强拍上，结尾淡出 2–3 秒 |
| 配音 | 一般不配；要旁白用 `zh_male` / `en_male`，语速 0.9×，句子短、句间留 1–2 秒 |
| 自检 | 遮幅上下对称、字不压在遮幅上；片名那一刻 `look`；音乐结尾有淡出；开头是黑场渐入 |

### 3. 科幻（`sci-fi`）

**什么时候用**：科技产品、AI 和未来题材、太空、赛博朋克城市、游戏宣传。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 看平台：16:9 或 9:16 |
| 时长 | 30–60 秒 |
| 结构 | **0–3 秒 启动**：黑场 + 打字机文字（`typewriter`）「SYSTEM ONLINE」、一行坐标或时间码；或者一次闪白（`whiteFade` 0.1 秒）进第一个镜头。<br>**铺陈**：冷色画面，1.5–3 秒一个镜头，快推移转场。<br>**高潮**：跟着拍子加速切，重拍上闪白。<br>**结尾**：标题 `strokeDraw`（描边长出来）或 `wipe`，停住，黑场 |
| 镜头 | 1.5–3 秒；高潮段 0.5–1.5 秒 |
| 转场 | 硬切为主；`whiteFade`（0.1–0.15 秒）当闪光；`pushLeft` / `pushUp` / `wipeLeft`（0.25 秒以内）。**闪白每 10 秒不超过 3 次**（光敏） |
| 画面动画 | `entrance: zoom` 或 `wipe`（0.3 秒）点缀 |
| 滤镜 | 赛博朋克 `neon`；冷硬工业 `coldIron`；太空、实验室 `mistBlue` 或 `coldWhite` |
| 文字 | 英文 `DIN Condensed` / `DIN Alternate`，HUD 标签用等宽的 `Menlo`；中文 `PingFang SC` 细体；全大写、字距拉宽（`letter_spacing` 10–30）；颜色青 `#00E5FF`、品红 `#FF2BD6` 或纯白。<br>角落放小的 HUD 标签（坐标、时间码、「REC」）：字号 28–36；再用 `set_shape` 的细线、方框做取景框（线宽 2–3），半透明的实心长方形（如 `#00E5FF33`）垫在标签后面当面板。<br>数字用数字滚动做倒计时、数据跳动。<br>结尾标题用 `strokeDraw` 要先有描边（`stroke_color`），不然用 `wipe`；停够 2 秒 |
| 字幕 | 有旁白就开，白字细体 |
| 配乐 | `find_audio` 搜 space / electronic / synth / dark / tense |
| 配音 | `zh_male` / `en_male`（或 `*_female_warm`），语速 1.0×；想要「舰载电脑」的感觉给旁白挂 `sound_scene: radio` |
| 自检 | HUD 字不压主体；闪白次数；结尾标题停够 2 秒 |

### 4. 纪录片（`documentary`）

**什么时候用**：旅行、自然、人文、探险（南极验收任务就是这套）、访谈故事、公司和人物故事。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 16:9（YouTube / B 站）；短视频版 9:16 |
| 时长 | 1–3 分钟；短视频版 30–60 秒 |
| 结构 | **开场**：最有力量的一个画面 + 一句旁白（或原声）提出问题、交代设定（「在地球的最南端……」）。<br>**展开**：按时间或地点排；每一段 = 一个远景建立 + 2–3 个中近景细节 + 一句旁白。<br>**高潮 / 转折**：最震撼的画面，音乐起来，旁白停。<br>**结尾**：回到远景，一句收束的话，`blackFade`，最后是署名 |
| 镜头 | 3–6 秒，让画面呼吸；动物、人的动作要完整 |
| 转场 | 硬切；段落之间 `crossFade`（1 秒）；开头结尾 `blackFade` |
| 画面动画 | 不用入场动画；照片、静止镜头用 `set_keyframes` 慢推（大小 1 → 1.05） |
| 滤镜 | 写实 `flatGrey` 或不加；寒冷场景 `mistBlue` / `coldWhite`；暖光 `warmSun`；强度 0.3–0.5，轻用 |
| 文字 | 地点和时间字卡：「南极半岛 · 1 月」，左下角，`Avenir Next` / `PingFang SC` 常规体 40–48，`fade`，4 秒。片名：`Songti SC` / `Baskerville` / `Optima`，居中，`fade` |
| 字幕 | 有旁白、采访就开：白字 + 轻阴影，底部，不要底框 |
| 配乐 | `find_audio` 搜 documentary / nature / calm / piano / hopeful / emotional；旁白时比人声低 15–18 dB；旁白的间隙让现场声（风、动物叫声）出来 |
| 配音 | `zh_male` / `en_male` 或 `*_female_warm`，语速 0.95×；旁白写短句（中文 ≤ 20 字、英文 ≤ 15 个词），句间留 1–2 秒给画面。旁白按段放在对应画面上（说企鹅时画面是企鹅） |
| 声音 | 保留有意义的现场声（`listen` 找响的地方、`look` 确认是什么） |
| 自检 | 旁白和画面对得上；每段旁白之间有空；结尾署名 |

### 5. 日常 vlog（`daily-vlog`）

**什么时候用**：日常记录、旅行 vlog、一天的生活、探店；偏卖东西的开箱用「带货」。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 9:16（抖音 / TikTok / 小红书） |
| 时长 | 30–60 秒，最长 90 秒 |
| 结构 | **0–2 秒 钩子**：当天最好看或最好玩的一个画面先放（「先剧透」），配一行大字（「周末去了……」）。<br>**按时间顺序**：出发 → 过程 → 高光 → 收尾，每个场景 3–5 个镜头。<br>**结尾**：一句感想，或一个问题引大家评论（「你们周末都去哪？」） |
| 镜头 | 1–2.5 秒；有节奏清楚的音乐就 `cut_to_beat`；说话的片段 `cut_speech` 去停顿（跳剪没关系） |
| 转场 | 硬切为主；换场景偶尔 `pushLeft` / `pushUp` |
| 画面动画 | `entrance: pop` / `zoom` 点缀，别每段都用 |
| 滤镜 | 暖 `warmSun`，胶片感 `fadedFilm`；强度 0.4–0.6 |
| 文字 | 手写 / 圆体：中文 `Yuanti SC`（圆体）、`Hannotate SC`（手札体）、`HanziPen SC`（翩翩体）—— **这三个要在「字体册」里下载**，没装就用 `PingFang SC`（`set_text` 会提醒没装）；英文 `Marker Felt` / `Noteworthy` / `Chalkboard SE`。字号 70–100，`pop` / `rise`，白字 + 阴影或黄字 |
| 字幕 | 开；逐词高亮（第 ④ 刀做完后）；大字，放在下安全区之上 |
| 配乐 | 轻快：`find_audio` 搜 bright / hopeful / guitar；**音乐库现在缺轻快的**，找不到就用原声、告诉用户可以给一首自己的。说话的地方音乐压低 |
| 配音 | 一般不配（原声就是 vlog 的味道）；要配用 `zh_female_warm` / `en_female_warm`，语速 1.05× |
| 自检 | 钩子在前 2 秒；字和字幕都在安全区里；结尾有互动的一句 |

## 四、配音音色（第 16、43 条）

剪辑风格里写的是**角色**，不是某个具体的声音；具体用哪个在运行时挑。

| 角色 | 用在 | SrtFlow 自己的声音（Kokoro，第 ③ 刀，用户听样音挑的） | 没下载时退到 macOS 的声音（第 ② 刀） |
| --- | --- | --- | --- |
| `zh_female_lively` 活泼女声 | 带货 | `zf_xiaoyi` | 中文女声里挑高级 > 增强 > 默认，音调略高（1.08） |
| `zh_female_warm` 温和女声 | vlog、纪录片 | `zf_xiaoxiao` | 同上，另一个女声（只有一个就同一个） |
| `zh_male` 男声（男青年） | 纪录片、电影开头、科幻 | `zm_yunxi` | 中文男声；**没装男声时退到女声并告诉用户去下载** |
| `en_female_lively` / `en_female_warm` | 同上 | `af_bella` / `af_heart` | 英文女声，同上 |
| `en_male` | 同上 | `am_fenrir`（不用 `am_michael`） | 英文男声 |
| `en_female_british` / `en_male_british` 英式 | 纪录片、电影开头 | `bf_emma` / `bm_george` | 英国的声音优先 |

- 角色名 2026-09-28 改过（第 49 条）：`zh_male_steady` / `en_male_steady` → `zh_male` / `en_male`，加两个英式角色。
- 54 个 Kokoro 音色都能按名字点（日、西、法、意、葡、印地各有自己的音色）。
- 没装高级、增强音色时照样配出来（默认质量），结果里写明去「系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音」下载哪一个。
- 对话里点名能换：给角色名、系统音色的名字，或者（第 ③ 刀之后）一段要克隆的声音。
- 语速写在卡上（带货 1.1×、电影开头 0.9× 这类），AI 调 `add_voiceover` 时传 `speed`；系统的 rate 和实际语速不是线性的，App 里按实测的表换。
- 第 ② 刀已做：`add_voiceover`（一句一个文件放在 `SrtFlow/配音`、一批放进新开的一条音频轨、`subtitles` 按词的时间出字幕）。

## 六、给 App 用的格式

内置的五张和用户存的都是同一种 .md（第 41 条）：开头几行 `key: value`，下面是正文。

```
---
id: product-promo
title: Product or course promo
use_for: Selling a product, promoting a course or service, app demos, unboxing.
---
（正文：上面那张卡的英文版）
```

`recipes` 不给名字时只回每套的 `id`、`title`、`use_for` 和来源（内置 / 用户的 / 用户改过的内置），给名字回全文。
