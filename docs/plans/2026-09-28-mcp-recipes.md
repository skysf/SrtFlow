## 一、剪辑风格怎么用

- **AI 自己挑**（第 39 条）：剪整片之前先调只读工具 `recipes` 看有哪几套、每套「什么时候用」，按用户的目的挑一套，
  **用一句话告诉用户挑了哪套**（「这条按带货的路子剪：前 3 秒放成品，30 秒以内」），再按它读全文、照着剪。
- **用户的话永远优先**：用户说了时长、平台、风格、要不要音乐，就照用户的；剪辑风格只补用户没说的部分。
- **卡是起点，不是死规矩**：素材不够（没有人声、没有产品特写、音乐库里没有合适的配乐）时按卡上写的退路走，
  并在做完时告诉用户缺了什么。
- **用户自己的剪辑风格**（第 41 条）：用户说「把刚才这套存成剪辑风格，叫 XX」，AI 用 `save_recipe` 按同样的格式写一份；
  和内置同名就是用户改过的那一版。

## 二、所有剪辑风格共用的规矩

1. **先摸清素材再动手**：`open_folder` → `look files`（一次看全部）或 `look shots=true`（长视频分镜头）→ 有人说话的
   `transcribe` → `listen`（音量、静音段）。挑镜头看画面，不看文件名猜。
2. **先问平台**（第 26 条）：用户没说发哪儿就问一次。抖音 / TikTok / 小红书 / Reels / Shorts → 9:16；YouTube / B 站 → 16:9。
3. **9:16 的安全区**：平台的按钮和文案会盖住画面**上 10%、下 20%、右 12%**。大字、字幕、要看清的东西都放在这之外
   （文字的 y 在 0.12–0.75 之间，x 在 0.08–0.85 之间）。
4. **字**：一屏只有一个重点；同一条片子最多两种字体；每行短（中文 ≤ 8 个字，英文 ≤ 5 个词）；字不压在人脸和主体上
   （`set_text` 回的 `block` 和 `look` 对一下）。
5. **声音**：有人声时配乐比人声低约 15 dB（`listen` 量，`edit_clip volume_db` 调）；没有人声时配乐约 −18 dB；
   开头 0.5 秒内要有声音；结尾让音乐落在它自己的结尾上（二之二第 20 条），不行再淡出（`fade_out`），不硬切。
6. **不编造**：数字、评价、学员人数、价格、链接一律只用素材和用户给的（第 27 条：课程推广不写价格，结尾用
   「点主页链接了解」这类通用话）。
7. **导出前自检**：每张卡最后一节的清单逐条过；`look` 时间线上几个关键时刻（开头、每段第一帧、结尾），`listen` 整条时间线；
   然后做二之四的「交片前再看一遍」。
8. **做完告诉用户**：用了哪套、多长、画幅、导出在哪；用了音乐库的音乐给出署名句（`music_credits`）。
9. **字幕的样子**：生成字幕、配音字幕**之前**先用 `edit_subtitles style` 设好（一行放多少按设的字号切）；只改这个工程，
   不动用户在烧录页记住的那套（方案第 54 条）。逐词高亮只亮 SrtFlow 自己从语音、配音做出来的句子（`get_subtitles` 会报
   `lines_with_word_times`）。
10. **字号按画面高度算**：`set_text` 的 `font_size` 和字幕的字号都是「1080 高的画面上多少像素」，9:16 的画面 1920 高，
    同一个数字画出来（相对画面宽度）是 16:9 的 1.78 倍。卡里的字号写明了是哪种画幅的；只写一个数的是 16:9 的，放到 9:16
    上除以 1.8。（2026-09-29 验收实剪：照原来写的 9:16「110–140」做的大字折成三行、顶出画面，字幕 68 一行只放得下一两个词）
11. **生成素材只写成条件句**（2026-09-29，方案第 57、58 条）：`generate_media` 只有用户填了 fal.ai 的 Key 才在工具清单里，
    而卡是一直读得到的，所以卡里一律写「如果你的工具里有 `generate_media`……」。有它时：只补素材里没有的（缺的空镜、音效、
    音乐库里没有合适的配乐），用户已有的素材不用它替；做之前先把估价（结果里的 `estimated_cost_usd`）告诉用户，视频尤其；
    超了每日额度或价格不明时 App 顶部的提示条会问用户、任务显示 `waiting_for_user`，要告诉用户去那里点；生成的视频
    **自带声音**，配乐 / 配音时把它压低或静音（`edit_clip volume_db` / `muted`）；视频先用最便宜的 `resolution 480p` 出草稿，
    留下的镜头再用 `1080p` 重做；生成内容的使用条款看各家服务商，SrtFlow 没替用户核对，署名句（`music_credits`）只管音乐库
    的音乐；不把生成的画面说成用户拍的。
12. **音效按这个顺序**（2026-09-30 用户定，[音效方案](2026-09-30-sound-effects.md)）：先 `find_audio kind=sound_effect` 在音效库里找录音 / 制作好的
    （whoosh、撞击、riser、风、冰、水、机械……，用 `add_clips` 的 `library_id` + `hit_at` 放）；没有合适的再用 `add_clips` 的 `sound_effect`
    本机合成（转场的 whoosh / riser / impact、出字的 pop / ding、快门、提示音），落点用 `hit_at` 压在切点或出字那一刻；两种都默认 −8 dB 压在人声下面。
    `generate_media kind sound_effect` 只留给两边都没有的真实声音（环境声、人群、动物），而且仍是条件句。

### 二之一、先出分镜表（2026-10-05）

第一刀之前先写一张分镜表，用几行发给用户，然后接着做（用户可以喊停或撤销这一轮；只有用户说过「先给我看方案」才等他点头）：

- 一句话：「这条片子告诉〈谁〉〈什么〉。」
- 每一拍一行：几秒到几秒；它的作用（钩子、铺陈、高潮、停顿、收尾）；用哪个镜头（文件和时间）；什么在动、怎么动 ——
  用一个动词（砸下、漂移、静止、画出来、数上去）；怎么交给下一拍（硬切，或者哪个转场、为什么）；声音（音乐的重音、
  一个音效、一次停顿、一句话）。
- 动手前先说出节奏，比如「快-快-停-快-高潮-歇-收」：高潮在哪？哪里让片子喘口气？
- 说不出作用的一拍，删掉。

### 二之二、品味：剪过的片子和拼起来的片子差在哪（2026-10-05）

某张卡自己的「品味」和这里不一样时，听那张卡的。

**节奏**
1. 镜头时长要有意地变：最长的至少是最短的 3 倍；同一个时长（相差 0.2 秒以内）不连续出现三次。一串快切之后停住的一个
   镜头，比再快一点更有力。
2. 每一段都有「起、停、收」：开头有劲，中间停一下，收得干脆。
3. 切在有事的地方：动作做完、一个眼神或手势、一个词。音乐推着走的地方（铺陈、高潮）踩拍子切（`cut_to_beat`），别处看
   画面要什么 —— 每个拍子都切，片子就像机器剪的。
4. 让重要的时刻落地：动作做完、话说完之后再留 0.5–1 秒才切走。
5. 每一刀都换景别或角度（远景接近景，不是同一个东西的两个远景）；跳剪只在故意的时候用（口播、vlog 的劲头）。

**挑镜头**
6. 只用素材里最好的两三成：清楚、光好、主体明确、人脸有表情。虚的、晃的、平淡的即使切题也不要；短而强胜过长而平。
7. 用手上最有力的画面开场，不是最先拍的那个。

**转场**
8. 转场要有意思：硬切是默认、也最有力；`crossFade` = 时间过去了、情绪延续；`blackFade` = 一章结束、开场或收尾；
   `whiteFade` = 揭晓时闪一下；推、擦 = 劲头，留给带货和 vlog。除了硬切，一条片子最多用两种，任意 10 秒里最多一个花哨转场。

**运动**
9. 不是每个镜头都要动：静止、慢推（`set_keyframes` 大小 1 → 1.04–1.08，整个镜头）、慢移（位置 x 或 y 挪 0.02–0.04）、
   素材自己的运动，轮着来。相邻两个镜头不做同一种运动，也不是每个镜头都动 —— 一串动之后的静止镜头就是一口气。
10. 缓动带情绪：像镜头的移动（推、移）用 `easeInOut`，进来停稳的用 `easeOut`，离开的用 `easeIn`，`linear` 只给贯穿整个
    镜头的很慢的漂移。
11. 不对称和错开：进场比出场长（文字 `animation_in_duration` 0.5–0.8 秒，`animation_out_duration` 0.3–0.4 秒）；字在它
    所在镜头切进来之后 0.2–0.3 秒才出，不卡在切点上；一组字一个接一个出，相隔 0.1–0.2 秒、整组 0.5 秒内出完，最重要的先出。
12. 口播在重点处推近（punch-in）：在重点那句开始处 `split_clip`，后半段放大 1.12–1.2 倍、框住脸（`edit_clip scale`；
    有关键帧的段用 `set_keyframes scale`，开头和结尾同一个值）；下一个意思回到宽的构图。一台机位就像两台。8–10 秒最多一次。

**字**
13. 整条片子一个强调色，从画面或品牌里取；其余字白色或近黑。强调用字重、字号或这个颜色，一次只用一种，不用斜体。
14. 主次：一屏只有一个大东西；标题是标签的 2–3 倍大；最多两种字体、两种字重。
15. 粗体无衬线大标题字距 0 或略负（到 −2）；小标签和优雅的大写字距拉宽（10–40）。
16. 字放得有意图：放在三分线上或贴着画面的一条边，每次边距一样（至少画面的 6%）；只有片名和庄重的时刻才居中。

**声音**
17. 声音先开场：第一个声音和第一个画面同时或更早。
18. 音乐最强的那一下就是片子的高潮：挪音乐（起点或 `source_in`）让它的重音、drop 落在高潮上，而不是把画面剪到音乐碰巧最强的地方。
19. 高潮前喘口气：最大的那一刻之前 0.3–1 秒几乎无声（用 `volume_curve` 把音乐压下去、不放音效），然后再砸下去。
20. 结尾落在音乐自己的结尾上：把曲子放到它最后一个音和画面一起结束。太长就保留开头和真正的结尾、拿掉中间一段：在两个
    强拍上 `split_clip`（`listen beats=true` 给强拍），两刀相隔整数小节（4、8 或 16 小节），中间那段 `delete_items`，结尾那段挪到
    `new_audio` 新轨、接在前半段停下的地方，前半段 `fade_out` 0.1、结尾段 `fade_in` 0.1。实在不行才在乐句中间淡出。
21. J-cut 和 L-cut：下一场的声音（环境声、音乐、一句旁白）比它的画面早进 0.3–1 秒，或者让一句话延续到下一个画面上。
    它把切点藏起来、拉着观众往前走。（视频段自己的声音跟着画面走；这一招用的是音频轨上的段。）
22. 音效是标点，不是装饰：每 2–3 秒最多一个，最大的放在高潮，安静的地方不放。

### 二之三、AI 剪片的通病（2026-10-05）

这些会让片子一看就是 AI 剪的，导出前对着时间线逐条查：

- 每个镜头一样长，或者每一刀都踩在拍子上；
- 每两个镜头之间都有 `crossFade`（或别的花哨转场）；
- 每个镜头都慢推；
- 每行字都居中、都卡在切点上出、都用同一个动画；
- 每一刀、每个字都配一个音效；
- 音乐从 0 秒满音量开始、在乐句中间淡出；
- 字压在脸上、每行字都垫底框、不止一个强调色；
- 滤镜开满强度，或者每段一个滤镜；
- 用 logo、慢淡入或最没意思的镜头开场；
- 不管素材是什么，每条片子都做一样的选择。

### 二之四、交片前再看一遍（2026-10-05）

卡上的清单过完之后，像观众一样再看一遍 —— 用 `look` 和 `listen`，不凭记忆。不过关的改掉，再用一句话告诉用户查了哪几样。

1. 海报：单独看高潮那一帧（大图）。它能当一张静帧发出去吗？不能就换镜头、改构图或改字。
2. 一眼看：4–6 个关键时刻一起看（小图）。每一帧最重要的是什么，一眼看得出吗？
3. 节奏：从 `get_timeline` 列出每个镜头的时长。它们跟着分镜表走吗（铺陈快、停顿处长）？大多数相差不到 0.3 秒就重剪。
4. 停顿还是断档：找出没有新镜头、没有字、没有声音事件的那几段。是你安排的停顿，还是片子自己停住了？
5. 声音：听高潮前后和结尾。高潮前有没有喘口气？音乐是不是和画面一起结束？

### 二之五、从参考片学一种风格（2026-10-05）

用户给了一个参考视频（预告片、广告、一段喜欢的电影），要它的风格时：

- 用 SrtFlow 自己的工具量：`look shots=true`（在哪切、每个镜头多长）、`listen beats=true`（速度、音乐在哪砸下去和收住、
  哪里静音）、`text_scan=true`（字卡；烧在画面里的字幕不管，除非用户问）、挑几帧 `look`（构图、颜色、字体、字怎么摆）。
- 量出来的东西用 `save_recipe` 写成一种风格，分节和预设风格一样：标杆、按秒的结构、节奏（每一段镜头时长的中位数和范围）、
  转场和多频繁、运动、字、声音、品味、别这样、清单。写数字，不写形容词。
- 学语法，不学内容：不用它的画面、音乐、logo、片名设计。
- 不从网上下载参考片；要文件找用户要（YouTube 的条款不允许下载，免费播放站多是盗版片源，方案第 31 条也定了 AI 不下载素材）。

## 三、五张卡

### 1. 带货 / 课程推广（`product-promo`）

**什么时候用**：卖东西、推广课程或服务、App 演示、直播切片、开箱种草。**卖的是课**时看本节最后「卖的是课」。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 短视频平台 9:16；YouTube 16:9 |
| 时长 | 15–30 秒（短视频）；最长 60 秒 |
| 标杆 | 抖音 / TikTok 上投放效果最好的短广告，用苹果产品片的用心来剪：第一秒就是结果，每一拍只说一件事，产品永远在最好看的样子 |
| 结构（30 秒版） | **0–3 秒 钩子**：结果先行 —— 最好看的成品、前后对比、最惊人的数字，或者一句戳痛点的话；同时出一行大字。不许用 logo、慢淡入开场。<br>**3–8 秒 痛点 / 场景**：为什么需要它。<br>**8–22 秒 卖点**：2–3 个卖点，每个 = 一个镜头 + 一句话 + 一行关键词大字；有数字的用数字滚动。<br>**22–27 秒 证据**：成果、前后对比、真实评价（素材里没有就跳过，不编）。<br>**最后 3–5 秒 号召**：「点主页链接了解」这类通用话，最后一帧停住至少 1.5 秒 |
| 镜头 | 1–3 秒一个，平均约 2 秒，同一个时长不连续出现三次；**每 2–3 秒画面必须变一次**（换镜头、画面放大入场、出字）。口播先 `cut_speech`：去口头禅、停顿缩到 0.15–0.25 秒 |
| 转场 | 硬切为主；换段落偶尔 `pushLeft` / `pushUp`（0.3 秒以内，整条片子只用一个方向）；揭晓成品 `whiteFade` 闪一下（0.15 秒），只这一次 |
| 画面动画 | 关键产品镜头 `entrance: pop` 或 `zoom`（0.3 秒），三个镜头里最多一个；静止的产品图用 `set_keyframes` 慢慢放大（大小 1 → 1.08，缓动用默认的 easeInOut）；其余镜头静止或靠素材自己的运动 |
| 滤镜 | 产品、室内、干净：`coldWhite`；生活场景：`warmSun`。强度 0.5–0.7，整条片子一个 |
| 文字 | 关键词大字：中文 `PingFang SC` 粗体，英文 `Avenir Next` 粗体（或 `Futura`）；字号 9:16 上 44–52（英文大写一行最多 14 个、中文最多 8 个），16:9 上 90–110；白字 + 深色描边，或纯色底框（`background_color`，用整条片子那一个强调色）；`animation_in: pop` 或 `cascade`；放在上三分之一（字幕在下）。数字用数字滚动（0 → 目标值，1 秒） |
| 字幕 | 开，大字粗体，逐词高亮：生成之前 `edit_subtitles style` 字号 16:9 上 56–64、9:16 上 42–48（一行三四个词）、`bold`、高亮 `#FFD400`、放大 1.1；9:16 再加 `position bottom`、`margin 0.22`（在平台按钮之上） |
| 配乐 | 轻快、明亮：`find_audio` 搜 bright / hopeful / electronic。**音乐库现在缺轻快的**：找不到合适的就不放，告诉用户可以给一首自己的 |
| 配音 | 有口播用原声。纯产品画面才配旁白：`zh_female_lively` / `en_female_lively`，语速 1.1× |
| 音效与生成素材 | 转场音效（推进时 whoosh、每个卖点的第一个关键词出字时 pop —— 不是每行都有、拍照时 shutter、揭晓时一个 impact）用 `add_clips` 的 `sound_effect`，`hit_at` 压在切点或出字那一刻；如果你的工具里有 `generate_media`：音乐库里没有轻快的就先用 `kind music`（「upbeat, bright, electronic, no vocals」）再问用户要一首；不生成产品画面 |
| 品味 | 第一帧就是海报：产品或结果又大又清楚（占画面 60–80%）配那行大字，0.3 秒内已经有东西在动。<br>关键词大字是关键的 2–5 个词，不是把说的整句话打出来；和那个词一起出（时间从 `transcribe` / `get_subtitles` 拿），最多早 0.2 秒。<br>节奏：两三个快镜头（0.8–1.5 秒），接一个停住的产品主镜头（2–3 秒、慢推）；花样要变，同一个套路不连用三次。<br>口播最有力的卖点那句推近（二之二第 12 条）。<br>一个强调色，取自产品或品牌，用在高亮和关键词底框上；其余字白色。<br>揭晓独占唯一的 `whiteFade` 和唯一的 impact；数字滚完落一声 ding 或 hit。<br>号召要稳：产品镜头停住，字升起或淡入，不放音效 |
| 别这样 | 每行字都 pop 进来、都配一声 pop；每个镜头都有关键词大字，或者把整句话打出来；每个镜头都 2 秒；一条片子里往好几个方向推；人声下面音乐满音量；结尾硬停；编出来的紧迫感（用户没给的倒计时、价格、「只剩 3 件」） |
| 自检 | 前 3 秒 `look`：有大字、有主体；每 3 秒画面有变化；人声清楚、音乐不盖人声；时长在范围内；最后一帧有号召、停够 1.5 秒；然后做二之四的「交片前再看一遍」 |

**卖的是课**（课程推广，第 27 条）：

- 先 `transcribe` 全部课，挑三样：**学完能做出来的东西**（成品、效果对比、最惊艳的一步操作）、**老师说得最有力的一两句**
  （「学完你能……」「这一招……」）、**课程覆盖了什么**（按章节归成 3 个模块）。
- 结构：钩子（成品或最有力的那句）→ 这门课教什么（3 个模块，各一个画面 + 一行字）→ 老师是谁（一句话，可省）→ 号召。
- 录屏类画面要看得清：`edit_clip` 放大到操作的那一块（`x / y / scale`），不要整屏缩在 9:16 里。
- 带 `WaterMark` 的素材照常用，除非用户说了不用。不写价格、不编学员人数和评分。

### 2. 电影开头（`cinematic-opening`）

**什么时候用**：短片、旅行片的开场，预告片感，作品集开头，品牌故事开头。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 16:9；上下加电影遮幅：两个实心黑色长方形（`set_shape` rectangle、`filled`、`#000000`、宽 1、高 0.128，y 分别是 0.064 和 0.936），从头到尾都在，画面就是 2.39:1 |
| 时长 | 30–90 秒 |
| 标杆 | 电影节短片的开头、A24 的片头：安静、笃定，每一帧都构过图，片名落下像憋着的一口气松开。镜头更少、更长、更好 |
| 结构 | **0–5 秒 冷开场**：黑场里先出声音（环境声或音乐的第一个音）0.5–2 秒，画面再 `blackFade` 渐入；第一个镜头是远景（交代在哪）。<br>**5–25 秒 铺陈**：慢，长镜头 3–6 秒一个，从远到近（远景 → 中景 → 特写），音乐慢慢起。<br>**片名**：先喘口气（0.5–1 秒几乎无声），再落在音乐最大的那个重音上，居中，停 3–4 秒。<br>**25–45 秒 加速**：一个比一个短（比如 2.5、2、1.6、1.2 秒），跟着拍子切（`cut_to_beat`，拍子不清楚就手剪），情绪往上走。<br>**收尾**：最后一个镜头比觉得够了再多停 1–2 秒，`blackFade`（1–1.5 秒）出，音乐同时结束 |
| 镜头 | 铺陈段 3–6 秒，加速段 1.5–2.5 秒（越往后越短）；动作要完整（不在动作中间切） |
| 转场 | 段内硬切；`crossFade`（0.8–1.5 秒）只用在时间过去的地方；段落之间 `blackFade`；不用推移、擦除、闪白 |
| 画面动画 | 最多隔一个镜头动一次：慢推（`set_keyframes` 大小 1 → 1.04–1.06，整个镜头，`easeInOut`）或慢移（位置 x 挪 0.02–0.03）。自己在动的镜头（运镜、走路的人）和片名下面那个镜头都静止。**原来这一栏要求「静止的镜头都慢推」，那正是 AI 剪片最常见的通病，2026-10-05 改掉** |
| 滤镜 | 大片感 `tealOrange`，怀旧 `fadedFilm`；强度 0.5–0.7（有人脸时取低的那头） |
| 文字 | 片名：英文 `Didot` / `Bodoni 72` / `Optima` 大写、字距拉宽（`letter_spacing` 20–40）；中文 `Songti SC`（宋体）；字号 90–120；米白（如 `#F2EEE6`）比纯白沉稳；`animation_in: focus`（1–1.5 秒），`animation_out: fade`（0.6 秒）；不压在遮幅上。<br>地名、年份：小字 `Avenir Next` / `PingFang SC` 常规体 36–44，左下角画面里（x 约 0.08），在它的镜头开始 0.5 秒后出，淡入 0.6 秒、淡出 0.4 秒，停 4 秒。除此之外不加字 |
| 字幕 | 默认关（没有对白）；有对白才开，白字小字、不要底框（字号 44–48、不高亮） |
| 配乐 | 宏大、动情：`find_audio` 搜 epic / trailer / opening / orchestral / emotional。挪音乐让它最大的重音落在片名上（挪段或它的 `source_in`），片名前 0.5–1 秒用 `volume_curve` 压下 8–12 dB，结尾落在音乐自己的结尾上（二之二第 20 条）；用不了结尾才淡出 2–3 秒 |
| 配音 | 一般不配；要旁白用 `zh_male` / `en_male`，语速 0.9×，句子短、句间留 1–2 秒 |
| 音效 | 片名落下那一刻：`add_clips` 的 `sound_effect` 一个 riser 接一个 impact（或 boom），两个的 `hit_at` 都是片名落下那一秒；别的地方不放 |
| 生成素材 | 如果你的工具里有 `generate_media`：缺远景空镜可以做（`kind text_to_video`，或用户给的照片 `kind image_to_video`），先 480p 出草稿；音乐库里没有够宏大的就 `kind music`（「orchestral, rising, cinematic, no vocals」）；生成的视频自带声音，压在音乐下面 |
| 品味 | 克制就是风格：一个片名、一张地名卡、同一时间只有一种运动；让安静和静止做事。<br>情绪靠对比：片名前长而安静，片名后越切越快，结尾再慢下来。<br>像拍静帧一样构图：地平线在三分线上，主体不居中，朝它看或走的方向留空。<br>片名就是高潮：它落下时别的东西都不动、不响 |
| 别这样 | 每个镜头都慢推；片名落在音乐随便一个地方；riser 后面没有砸下去的那一声；片名和一张地名卡之外还有字；字垫底框；前 15 秒就快切；`crossFade` 和 `blackFade` 之外的转场 |
| 自检 | 遮幅上下对称、字不压在遮幅上；片名那一刻 `look`：它是整条片子构图最好的一帧；片名前有喘气的那一下；音乐和画面一起结束（自己的结尾，或 2–3 秒淡出）；开头先在黑场里出声音再渐入；然后做二之四的「交片前再看一遍」 |

### 3. 科幻（`sci-fi`）

**什么时候用**：科技产品、AI 和未来题材、太空、赛博朋克城市、游戏宣传。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 看平台：16:9 或 9:16 |
| 时长 | 30–60 秒 |
| 标杆 | 做得好的游戏或科技发布会预告：冷、精确、机械的节奏；界面图形像显示屏上的仪表，不像贴在视频上的贴纸 |
| 结构 | **0–3 秒 启动**：黑场 + 打字机文字（`typewriter`）「SYSTEM ONLINE」、一行坐标或时间码；或者一次闪白（`whiteFade` 0.1 秒）进第一个镜头。<br>**铺陈**：冷色画面，1.5–3 秒一个镜头，中间一两个 3–4 秒的诡异停顿，快推移转场。<br>**高潮**：跟着拍子加速切，重拍上闪白。<br>**结尾**：静 0.5 秒，然后标题随一声 boom `strokeDraw`（描边长出来）或 `wipe`，停住，黑场 |
| 镜头 | 1.5–3 秒；高潮段 0.3–1 秒 |
| 转场 | 硬切为主；`whiteFade`（0.1–0.15 秒）当闪光；`pushLeft` / `pushUp` / `wipeLeft`（0.25 秒以内）。**闪白每 10 秒不超过 3 次**（光敏） |
| 画面动画 | `entrance: zoom` 或 `wipe`（0.3 秒）点缀 |
| 滤镜 | 赛博朋克 `neon`；冷硬工业 `coldIron`；太空、实验室 `mistBlue` 或 `coldWhite` |
| 文字 | 英文 `DIN Condensed` / `DIN Alternate`，HUD 标签用等宽的 `Menlo`；中文 `PingFang SC` 细体；全大写、字距拉宽（`letter_spacing` 10–30）；颜色青 `#00E5FF` 或品红 `#FF2BD6`（整条片子只用其中一个）加白色。<br>角落放小的 HUD 标签（坐标、时间码、「REC」）：字号 16:9 上 28–36、9:16 上 16–20；再用 `set_shape` 的细线、方框做取景框（线宽 2–3），半透明的实心长方形（如 `#00E5FF33`）垫在标签后面当面板。<br>数字用数字滚动做倒计时、数据跳动。<br>结尾标题用 `strokeDraw` 要先有描边（`stroke_color`），不然用 `wipe`；停够 2 秒 |
| 字幕 | 有旁白就开，白字细体、不高亮 |
| 配乐 | `find_audio` 搜 space / electronic / synth / dark / tense |
| 配音 | `zh_male` / `en_male`（或 `*_female_warm`），语速 1.0×；想要「舰载电脑」的感觉给旁白挂 `sound_scene: radio` |
| 生成素材 | 如果你的工具里有 `generate_media`：素材里没有的太空、城市、机舱镜头用 `kind text_to_video`（冷色、慢推）；UI 提示音（beep、click）、whoosh、glitch、冲进高潮的 riser、标题的 boom 用 `add_clips` 的 `sound_effect`；开机嗡鸣这类真实的声音才用 `kind sound_effect`；配乐 `kind music`（「dark synth, tense, pulsing」）；每条视频先 480p 看效果 |
| 品味 | 精确：所有 HUD 标签在同一套网格上（边距一样、标签对齐在同一个 x 上）；动画短（0.2–0.4 秒）、正好落在事件上。<br>先框后字：线和方框先画出来（`set_shape` 的 `animation_in` 用 draw，0.3–0.5 秒），框里的字晚 0.1–0.2 秒再出（打字机或淡入）。<br>节奏的对比：诡异的停顿，接高潮的极短快切。<br>一个霓虹强调色加白色；滤镜 `coldIron` 或 `mistBlue`，强度 0.6–0.8（只有赛博朋克城市才用 `neon`）。<br>声音设计领路：每个 HUD 事件一声 glitch / beep / click，riser 冲进高潮，静一下，再一声 boom |
| 别这样 | 每一刀都 glitch；每个镜头都有 HUD；每个拍子都闪白；青色和品红一起用；字同时有描边、阴影和底框；弹来弹去的动效 —— 科幻里东西是「咔」地卡到位的 |
| 自检 | HUD 字不压主体；闪白次数；结尾标题停够 2 秒；然后做二之四的「交片前再看一遍」 |

### 4. 纪录片（`documentary`）

**什么时候用**：旅行、自然、人文、探险（南极验收任务就是这套）、访谈故事、公司和人物故事。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 16:9（YouTube / B 站）；短视频版 9:16 |
| 时长 | 1–3 分钟；短视频版 30–60 秒 |
| 标杆 | BBC 的自然历史片、国家地理，加上 PBS Frontline 的克制：画面讲故事，旁白只说画面说不了的，字有博物馆标签的那种安静 |
| 结构 | **开场**：最有力量的一个画面 + 一句旁白（或原声）提出问题、交代设定（「在地球的最南端……」）。<br>**展开**：按时间或地点排；每一段 = 一个远景建立 + 2–3 个中近景细节 + 一句旁白。<br>**高潮 / 转折**：最震撼的画面，音乐起来，旁白停。<br>**结尾**：回到远景，一句收束的话，`blackFade`，最后是署名 |
| 镜头 | 3–6 秒，最有力的画面 6–8 秒，让画面呼吸；动物、人的动作要完整 |
| 转场 | 硬切；段落之间 `crossFade`（1 秒）；开头结尾 `blackFade` |
| 画面动画 | 不用入场动画；照片，偶尔一个静止镜头，用 `set_keyframes` 慢推（大小 1 → 1.05，缓动用默认的 easeInOut）；其余都静止 |
| 滤镜 | 写实 `flatGrey` 或不加；寒冷场景 `mistBlue` / `coldWhite`；暖光 `warmSun`；强度 0.3–0.5，轻用 |
| 文字 | 地点和时间字卡：「南极半岛 · 1 月」，左下角，`Avenir Next` / `PingFang SC` 常规体 40–48，`fade`，4 秒。片名：`Songti SC` / `Baskerville` / `Optima`，居中，`fade` |
| 字幕 | 有旁白、采访就开：白字 + 轻阴影（`shadow #00000099`），底部，不要底框、不高亮（`highlight none`） |
| 配乐 | `find_audio` 搜 documentary / nature / calm / piano / hopeful / emotional；旁白时比人声低 15–18 dB；旁白的间隙让现场声（风、动物叫声）出来 |
| 配音 | `zh_male` / `en_male` 或 `*_female_warm`，语速 0.95×；旁白写短句（中文 ≤ 20 字、英文 ≤ 15 个词），句间留 1–2 秒给画面。旁白按段放在对应画面上（说企鹅时画面是企鹅） |
| 声音 | 保留有意义的现场声（`listen` 找响的地方、`look` 确认是什么） |
| 音效与生成素材 | 换章节的一声 whoosh 或 downlifter 用 `add_clips` 的 `sound_effect`（`hit_at` 压在切点）；如果你的工具里有 `generate_media`：只补**声音** —— 素材现场声不能用时垫一层环境声（风、海、人群，`kind sound_effect`），音乐库没有合适的用 `kind music`；**不生成**地点、动物的画面，纪录片放的是真拍到的 |
| 品味 | 静止就是权威：不用入场动画、不用花哨转场，运动来自素材本身。<br>最有力的画面停得比舒服的再久一点；新场景的现场声先放 1–2 秒，旁白再进。<br>先画面后话：一句旁白在它说的那个镜头开始 0.5–1 秒后才进，说画面说不了的。<br>场景之间用 J-cut：下一个地方的环境声或音乐比画面早 0.5–1 秒进。<br>地点时间卡永远在同一个边距（左下，x 约 0.08），小字常规体，淡入 0.6 秒、淡出 0.4 秒。<br>音乐在开场那句旁白之后才进，不压在它的第一个字上；只在高潮、旁白停下时起来，落在自己的结尾上 |
| 别这样 | 音乐从头铺到尾、一个音量；为了煽情用 impact、riser、whoosh —— 纪录片的情绪来自真实的声音；改变地方气质的调色（`neon`、`tealOrange`、开满强度的滤镜）；描述画面的旁白（「我们看到了企鹅」） |
| 自检 | 旁白和画面对得上；每段旁白之间有空；结尾署名；然后做二之四的「交片前再看一遍」 |

### 5. 日常 vlog（`daily-vlog`）

**什么时候用**：日常记录、旅行 vlog、一天的生活、探店；偏卖东西的开箱用「带货」。

| 项 | 怎么做 |
| --- | --- |
| 画幅 | 9:16（抖音 / TikTok / 小红书） |
| 时长 | 30–60 秒，最长 90 秒 |
| 标杆 | 小红书 / YouTube 上顶尖的生活博主：亲近、温暖，生活忙的地方剪得快，好看的地方停得住 |
| 结构 | **0–2 秒 钩子**：当天最好看或最好玩的一个画面先放（「先剧透」），配一行大字（「周末去了……」）。<br>**按时间顺序**：出发 → 过程 → 高光 → 收尾，每个场景 3–5 个镜头。<br>**结尾**：一句感想，或一个问题引大家评论（「你们周末都去哪？」） |
| 镜头 | 1–2.5 秒，每个场景留一个 3–5 秒的真实时刻；有节奏清楚的音乐就把忙的那几段 `cut_to_beat`；说话的片段 `cut_speech` 去停顿（跳剪没关系） |
| 转场 | 硬切为主；换场景偶尔 `pushLeft` / `pushUp` |
| 画面动画 | `entrance: pop` / `zoom` 点缀，别每段都用 |
| 滤镜 | 暖 `warmSun`，胶片感 `fadedFilm`；强度 0.4–0.6，整条片子一个 |
| 文字 | 手写 / 圆体：中文 `Yuanti SC`（圆体）、`Hannotate SC`（手札体）、`HanziPen SC`（翩翩体）—— **这三个要在「字体册」里下载**，没装就用 `PingFang SC`（`set_text` 会提醒没装）；英文 `Marker Felt` / `Noteworthy` / `Chalkboard SE`。字号 9:16 上 44–52（16:9 上 80–100），`pop` / `rise`，白字 + 阴影或黄字 |
| 字幕 | 开，大字，逐词高亮但不放大：`edit_subtitles style` 字号 9:16 上 42–48（16:9 上 52–60）、高亮 `#FFD400`、放大 1；9:16 再加 `position bottom`、`margin 0.22` |
| 配乐 | 轻快：`find_audio` 搜 bright / hopeful / guitar；**音乐库现在缺轻快的**，找不到就用原声、告诉用户可以给一首自己的。说话的地方音乐压低 |
| 配音 | 一般不配（原声就是 vlog 的味道）；要配用 `zh_female_warm` / `en_female_warm`，语速 1.05× |
| 音效与生成素材 | 钩子大字出来的 pop、换场的 whoosh 用 `add_clips` 的 `sound_effect`（`hit_at` 压在那一刻，不花钱），不是每行字都配；如果你的工具里有 `generate_media`：只补音乐库里找不到的轻快配乐（`kind music`）；不生成画面 |
| 品味 | 按时刻定节奏：准备出门、在路上用快剪（0.5–1.2 秒一个、踩拍子），接一个停 3–5 秒的真实时刻，放它自己的声音、音乐压低 6–10 dB（`volume_curve`）。这个对比就是味道。<br>真实的声音是宝：一声笑、滋滋的油、关门、一句「哇」，让它出来。<br>字像日记里的批注：短、私人（「终于！」「排了 30 分钟」），放在它说的东西旁边，稍微歪一点（`rotation` −4 到 4），不居中；一个强调色。<br>说话的跳剪没关系；好笑的那句推近（二之二第 12 条）。<br>结尾要静：一个安静的镜头（日落、一杯咖啡、走远的背影）配那句提问，音乐和它一起结束 |
| 别这样 | 每个镜头都 pop 进来或都配音效；字说的是画面里已经看到的（「咖啡」）；没有人、没有理由的长空镜；音乐一个音量从头到尾、盖住所有真实的声音 |
| 自检 | 钩子在前 2 秒；字和字幕都在安全区里；结尾有互动的一句；然后做二之四的「交片前再看一遍」 |

## 六、给 App 用的格式

内置的五张和用户存的都是同一种 .md（第 41 条）：开头几行 `key: value`，下面是正文。

```
---
id: product-promo
title: Product or course promo
use_for: Selling a product, promoting a course or service, app demos, unboxing.
---
（正文：上面那张卡的英文版）
```

`recipes` 不给名字时只回每套的 `id`、`title`、`use_for` 和来源（内置 / 用户的 / 用户改过的内置），给名字回全文。
