# 隐藏扩到所有块、回到开头、对齐线整套、字幕拆成两条独立轨（2026-09-26）

## 背景

2026-09-26 用户一次拍了五件事，要求**一个 PR、多个 commit**：

1. 上层视频轨上按 V 藏起来的段，成片里画面还在（bug）。
2. 隐藏（V / 右键）扩到文字、形状、滤镜段和字幕单句。
3. Return / Home 把播放头送回开头。
4. 2026-09-25 讨论过的对齐线规格整套落地（含裁切的吸附）。
5. 字幕拆成两条**独立**的轨 —— 推翻 2026-08-09「译文是原文的镜像、UI 不许承诺独立」那条。

第 1–4 件的约束已经写进各自的架构文档（见下面「落在哪」），这里只记拍过的板。第 5 件改动最大，
下面单独展开：用户拍的板、以及实现时我定下来的细节和理由。

## 拍过的板（第 1–4 件）

## 字幕拆成两条独立轨

### 用户拍的板

- 原文、译文各自的身份和时间：挪 / 裁 / 删 / 拆 / 藏**互不影响**；字幕块加左右把手（能裁）。
- 画面上**各自的位置和大小、可以分别拖**；默认原文在上、译文在下，一句换行变高时另一句自动让开。
- 重译：
  - 「全部翻译（Translate All）」= 清空译文轨、整条重建；**有手改过的先确认**。
  - 「只翻缺的和改过的（Translate Missing & Stale）」= 只补新句、只换原文改过字的句；
    **原文没改的句子，连手改过的译文字也不动**；不动用户调过的时间，没动过时间的跟着原文的新时间走
    （防止原文拆句后两句译文叠在一起）；用户拆过 / 合并过的译文不再自动更新。
- 右栏字幕表：**一张表按时间交错排**，行首标出是哪条轨，加行加到选中的那条轨。
- 仍然只有两条（多语言不做）；工程格式升版，老工程打开时自动拆开；换掉原文（外挂新 .srt / 重新生成）
  照旧清掉译文；字幕句不能在两条轨之间拖。

### 我定的细节

| # | 板 | 为什么 |
| --- | --- | --- |
| S1 | 译文 cue 有自己的 ID，另记一张**来源表**（`TranslationLink`，键是译文 cue 的 ID）：从哪几句原文翻来的、翻的时候原文是什么字、拆 / 合并过没有、时间 / 文字手动改过没有 | 身份独立之后「这句译文对应哪句原文」不能再靠 ID 相等；放旁表不改 `SubtitleCue` 的存盘格式（`cueMeta` 同一个做法） |
| S2 | 「过期」不再存标记，**现算**：来源只有一句、没拆合过、翻的时候的原文 ≠ 现在的原文 → 过期 | 存标记要在每个改原文的入口记得打，现算只有一处；老工程里标过过期的，迁移成「翻的时候的原文未知」，照样算过期 |
| S3 | 手改译文的字 = 这句译文跟上了现在的原文（不再过期），同时记「文字手改过」；原文之后再改字，照样算过期、重译照样换 | 与以前「改译文清 stale」同一语义；「文字手改过」只用来决定全部重译前要不要确认 |
| S4 | 「缺译文」= 没有任何一句译文的来源里有它。手动在译文轨上加的一行，来源记成加的那一刻和它重叠最多的那句原文，并算「拆合过」（永远不自动更新） | 否则用户自己写的译文旁边，「只翻缺的」又补一句机翻叠在一起 |
| S5 | 原文合并：被并掉的那几句原文，指向它们的译文来源改指向留下的那句；重译时同一句原文底下有几条会自动更新的译文，留最早的一条换字，其余没手动改过时间 / 文字的删掉 | 原文合并后字变了，几条译文都过期；各自跟着原文新时间走就会叠在一起 |
| S6 | 原文删掉，译文不跟着删（来源悬空，重译不碰它） | 「删互不影响」；悄悄删掉用户看得见的东西不行 |
| S7 | 画面上两条轨的位置：`subtitleLayout` 仍是原文的；新增 `translationLayout`，**nil = 叠在原文下面**（和原文排成一块，原文在上、译文在下，一句换行变高另一句自然让开）；有值 = 各自一块、各摆各的 | 老工程（只有 `subtitleLayout`、双语排成一块）不用迁移、成片一模一样；「自动让开」靠排成一块天然成立，预览和烧录不用各自猜对方的行高 |
| S8 | 叠在一起时，预览上选中哪条轨的一句，框就只框那条轨的那几行；拖它（移动 / 拉边 / 拉角）**两条就此分开**：被拖的跟手，另一条原地钉住（换成自己的布局，不跳） | 「可以分别拖」；另一条要是跳到默认位置，拖的那一下画面会闪 |
| S9 | 分开之后在字幕表表头有一个「译文叠在原文下面」的开关，点一下合回去（`translationLayout = nil`） | 分开了总得能合回去；右键菜单里藏着找不到 |
| S10 | 预览和烧录读**同一份按时间切好的块**（`SubtitleRenderPlan`）：叠在一起时两条轨的句子按「此刻谁在屏上」切成一段段，每段一个事件（原文行在上、译文行在下）；分开时每条轨各一块、各一个 ASS 样式，放在不同的 Layer（libass 不让两块互相避让，和预览一致） | 两条轨的句子起止不再对齐，不切的话烧录没法把两句排成一块；同一份切法两边共用，预览看到的就是成片 |
| S11 | 同一条轨里重叠的几句也并进同一段（以前是各自一个事件、靠 libass 往上叠） | 两边只剩一种排法；预览本来就是把它们拼成一块画的 |
| S12 | 字幕表每行只编一句（原文或译文），行首一个橙 / 青色的轨道标记；藏起来的轨的行灰显、不能编；加行加到选中那句所在的轨（没选中时加到原文轨） | 交错排之后「一行两格」对不齐了；颜色和时间线上两行一致 |
| S13 | 时间线 / 预览上双击，浮层只编被双击的那一句 | 两条轨已经不是一一对应，「一个浮层两格」说不清第二格是哪一句 |
| S14 | 合并只合同一条轨上的；选中的句子跨两条轨时合并按钮置灰 | 跨轨合并没有意义 |
| S15 | 工程格式 v23；老工程打开时拆开：每句译文换新 ID，来源记成原来那句原文、翻的时候的原文记成现在的原文（标过过期的记成未知） | 老版本打开新工程会把译文当成原文的镜像按 ID 对，全对不上被丢掉 |

### 没做的

- 多语言（N 条译文轨）：用户明确说不做。
- 字幕句在两条轨之间拖：用户明确说不做。
- 分开后「挨近了自动吸回叠在一起」：先用表头的开关，手感不够再说。
