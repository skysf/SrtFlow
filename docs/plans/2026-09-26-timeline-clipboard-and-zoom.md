# 时间线上的复制 / 剪切 / 粘贴，缩放以鼠标为中心 + 纵向缩放（2026-09-26）

## 背景

2026-09-26 用户提了两件事，先讨论、后动手（「目前我们只讨论，不做任何修改，你有什么问题？」）：

1. **轨道上的任何东西都能复制、剪切、粘贴**，快捷键也要有。粘贴的位置**优先是鼠标停留的位置**，鼠标不在
   轨道上就按「预览线」（白色播放头）停的位置。
2. **捏合缩放时鼠标停留的那一块不许动**：放大「往两边延伸，延伸的点就是鼠标停留的点」；另外加一个
   **纵向的整体缩放**。

讨论时查到：复制粘贴当时只有滤镜段有（⌘V 另外能粘 Finder 里复制的文件，落在播放头）；捏合的「以鼠标为中心」
其实写了，但锚点那一步因为传错坐标系从来没生效（[案例](../bugfixes/2026-09-26-pinch-zoom-anchor-never-applied.md)）。
我列了 5 个问题 + 一串默认做法 + 一个顺带的问题，用户逐条回：**1A 2A 3A 4A 5B**，顺带的「一起修改吧」，
默认做法没有异议。

### 默认做法（讨论时列给用户、没有异议）

- 「预览线」= 白色播放头。「鼠标在轨道上」= 时间线的轨道区（含右边、下边撑出来的空白）；标尺和左边
  轨道头那一列不算。
- 粘到哪条轨：鼠标指着的那一行放得下这种东西就粘那行；放不下（比如视频指着音频轨）或者用播放头粘时，
  回到它原来那条轨。一次复制了好几条轨上的东西时，整组保持原来的前后间隔和上下关系，只用落点定时间。
- 落点对齐粘贴内容的左边缘；按鼠标粘时照样吸附（和拖文件一样），按播放头粘时不吸。
- 范围：剪辑（视频 / 图片 / 声音）、文字和数字、形状、滤镜、两条字幕轨的句子。标记跟着它所在的那段一起走，
  转场只在两边的段都被复制时才带上；关键帧、动画、音量曲线、声音场景、速度这些属性全部照抄。
- 链接开着时，复制视频会连带它链接的音频（和 ⌫ 删除同一规则），粘出来的一对彼此链接。
- 剪切 = 复制 + ⌫：主轨磁吸开着时，剪掉后空档自动合拢，和删除一样。
- 字幕句：鼠标指着哪条字幕轨就粘到哪条（原文 / 译文都行），否则回原来那条；允许和已有的句子重叠。
- 支持跨工程：这个工程复制、另一个工程粘（走系统剪贴板）。
- 粘完选中粘出来的东西，播放头不动；⌘Z 一次撤掉整次粘贴。
- 右键菜单加「拷贝 / 剪切 / 粘贴」，在空白处右键粘贴就落在点的地方。
- 滤镜和 Finder 文件现在的 ⌘V 也改成同一条「鼠标优先、否则播放头」的规则。

## 我定的实现细节

| # | 板 | 为什么 |
| --- | --- | --- |
| Z1 | 捏合的锚点从时间线自己的 `TimelineScrollGeometry` 量，不再按坐标 hitTest 找滚动视图；缩放统一走 `TimelineZoom`，推滚动只由 `keepAnchored` 做（同一拍挪一次、下一轮再挪一次） | 修 bug 的那一刀（[案例](../bugfixes/2026-09-26-pinch-zoom-anchor-never-applied.md)）；只挪一次要么抖一帧、要么放大时被旧尺寸夹住 |
| Z2 | 一轮捏合起手时定轴（按着 ⌥ = 纵向）、定锚点；`began` 永远开新的一轮 | 捏到一半松开 ⌥ 不该突然换轴；上一轮的 `ended` 万一没来，不拿旧锚点接着缩 |
| Z3 | 纵向锚点按**行**认（行内的第几成 / 行下沿往下多远），不按 y 认 | 行高一变 y 就不是那一处了；按行认，连续缩放每一拍复用同一个锚点也不漂 |
| Z4 | 统一高度的起点 = 锚点那一行现在的高度（不在视频 / 音频轨上就用主轨的） | 鼠标底下那一行不能一上来就跳一下；区间取两类的交集 28…200，「一样高」两类都够得着 |
| Z5 | 统一高度存进工程（`rowHeights.uniform`），不进撤销栈、不开新的 formatVersion | 单独拖的行高本来就这样存；横向比例不存（每次打开回到默认），纵向是「行高」的一种，跟行高走 |
| Z6 | ⌘↓ / ⌘↑ 一档 ×1.25：鼠标在时间线上钉鼠标那一处，不在就钉视口正中 | 从默认视频轨高度 54 到上限 200 大约六下 |
| Z7 | 行怎么排只剩一份：`TimelineRowList.rows(for:)`（从时间线视图里挪出来） | 纵向缩放和粘贴都在时间线视图树外面，又不许各排一份 |
| C1 | 复制粘贴的载荷走**系统剪贴板**、自己的类型 `com.srtflow.timeline-items`（Info.plist 里声明），不写纯文本；滤镜原来那套剪贴板（`com.srtflow.filter-clip`）并进来删掉 | 跨工程天然成立（滤镜那套本来就是这么做的）；同一件事两份剪贴板，迟早有人读错 |
| C2 | 载荷里每一样都是**完整的一份**（和存盘同一套编码），粘贴时换新身份：编码、换掉顶层的 `id`、再解回来 | 手写「复制除了 id 以外的每个字段」迟早漏字段（分割那条路就漏过 `remoteKey` 和 `isHidden`，同一个 PR 里补上了，[案例](../bugfixes/2026-09-26-split-drops-hidden-and-library-key.md)），存盘的编码本来就是「这一段的全部」 |
| C3 | 剪辑按「原来那条轨」分组：画面组从下往上落（上面的组永远落在下面的组之上，保住叠放关系），每组整组落在同一条轨上，撞上就整组往上抬；声音组各自找一条放得下的、互不共用；需要新开的每组各开一条 | 一组拆到几条轨上就不是「整组保持原来的上下关系」了；画面有叠放次序、声音没有（同拖文件那套梯子） |
| C4 | 转场：复制时就把「下一段没被复制」的那段的转场去掉；粘贴落到上层轨的段一律去掉 | 转场只有主轨有语义；复制时才知道下一段是谁 |
| C5 | 链接组换一个新的组号；只复制到组里一个成员时不留组号 | 粘出来的一对彼此链接、不和原来那对链在一起；一个人的链接组没有意义 |
| C6 | 文字 / 滤镜：从「指着的那一行 / 那一层（单一来源时）」或「原来那一行 / 那一层」起往上找第一个空的，都满了开新的一行 / 一层，最后收拢空行 | 和拖文字换行、拖滤镜卡片落层同一套「往上找空的」 |
| C7 | 右键菜单上的拷贝 / 剪切：右键的那块在选中集合里就作用于整个选择，不在就先单选它 | Finder / 各家剪辑软件都是这样；右键一块没选中的东西却拷贝了别的，说不清 |
| C8 | 右键菜单的「粘贴」落在右键按下的那一处（时间线的事件监视器记下来），不落在菜单项底下 | 菜单弹出来之后指针已经在菜单项上了 |
| C9 | 右键菜单里的「粘贴」不按剪贴板有没有东西置灰，剪贴板空的时候点了响一声 | 右键菜单的内容可能跟着块的 body 一起算，每个块每次重算都去读一遍剪贴板太贵；编辑菜单里的「粘贴」照旧按剪贴板亮灭 |

## 没做的

- ⌥ 拖动复制、⌘D 原地复制一份（讨论时提过，这次不做）。
- 纵向缩放不带动字幕 / 文字 / 形状 / 滤镜那几条细行（4A）。
- 复制的东西不带「它原来在哪个工程」：跨工程粘贴时，定格的那张 PNG 还在原来的工程文件夹里，被搬走才触发重链接
  （同[定格](../architecture/freeze-frame.md)「工程另存到别的文件夹」那条）。
