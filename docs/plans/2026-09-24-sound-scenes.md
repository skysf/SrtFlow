## 一、目标（用户原话）

> 选中轨道里的音频文件的时候，这里多一个功能，就是允许用户设置这个声音，比如像从喇叭里出来的，
> 像在室内，像室外，像浴室，像海边，像森林，然后也允许调整应用后的一些参数。

讨论时说明了「预览走 AVFoundation、成片走 ffmpeg，每个声音效果都要接两处线」，用户回：

> 不能做一遍吗？感觉两遍效率很低啊

于是拆成两步：**先让成片的声音直接从预览那份混音里读出来**（之后任何声音功能都只做一遍），
再把声音场景只做在预览那一套里。用户：「可以，按照你的建议来」。

## 二、拍过的板（2026-09-24）

逐条讨论过，用户对每条回了「可以 / A / 按你的建议」。推翻前先读理由。

| 决定 | 口径 | 理由 |
| --- | --- | --- |
| 两步走 | ① 成片的声音 = 预览那份合成的混音，离线读成文件，ffmpeg 只编码、和画面合在一起；② 声音场景只做在预览那一套里 | 用户嫌两遍低效。① 之后音量、渐变、曲线、推子、场景都只有一份实现，「预览听着对、成片不对」这一类从根上没了；导出里专为模仿预览写的 `aeval` 平衡树、`afade` / `adelay` 的先后规矩整块退役 |
| 场景清单 | 9 个，分三组：**喇叭**（电话、扩音器、收音机）、**室内**（房间、浴室、大厅）、**室外**（室外、森林、山谷回声） | 用户列的六个去掉海边，加上建议的大厅、山谷回声；「喇叭」选了差别最明显、短视频里最常用的三种 |
| 海边 | **不做** | 空旷的室外几乎没有混响，不带海浪声的话，海边和室外听不出区别。环境声（海浪、鸟叫）是左栏「音频」页里音效的事（用户：素材在 `AI_Video_SouthPole/SoundEffects`），不归这个功能 |
| 森林 | 保留，做成很淡、很暗的散射尾音 | 树干和枝叶的散射在声学上确实有一条短而暗的尾巴，能和空旷的室外分开 |
| 效果只能加空间 | 素材自带的房间回声去不掉，套「室外」也变不干 | 声学事实，界面文案不许暗示能去混响 |
| 参数 | 每个场景 2–3 个好懂的滑杆：都有「强度」（0 = 原声）；空间类「空间大小」「距离」；喇叭类「失真」「音质」（频带宽窄）；外加「恢复默认」。**不做「高级」区** | 用户选 A |
| 余音 | **越过段尾自然消失**（最多几秒）；同一条轨上紧跟着的下一段和这截余音叠在一起 | 用户同意。截断的话，最后一个字贴着段尾时余音、回声会被一刀切掉，要用户自己往后拖出空白 |
| 效果排在链上的哪儿 | 段的音量 / 曲线 / 淡入淡出**之后**，轨道推子和总推子**之前** | 人声淡出时余音照常散完（Logic 的 region → insert → fader）；拉推子连余音一起变小。余音越过段尾，只有这个顺序讲得通 |
| 工程末尾 | 最后一段的余音不把成片拉长，到结尾就停 | 成片时长只由段决定（同 FCP） |
| 适用范围 | 凡是有声音的段（音频段 + 视频自带的声音），和检查器「音量」那一块同一个条件 | 口播、录屏的人声就在视频块里 |
| 叠加 / 随时间变 | 一段只选一个场景，不叠加；整段一个设定，不随时间变（要变就先分割） | 需求里没有组合；关键帧化的效果参数没有真实用例 |
| 批量 | 框选多段时一次套用 | 同入场动画的批量套用 |
| 界面 | 检查器「音量」下面一块：按「喇叭 / 室内 / 室外」分组的下拉菜单，选了场景才出现滑杆；块上一个小图标表示挂了效果 | 检查器很窄，九宫格放不下 |
| 响度 | 切换场景自动补偿响度，换来换去不忽大忽小 | 用户比的是「像不像」，不该被响度差带偏 |
| 电平表 / 波形 | 电平表显示加效果之后的；波形照旧画「原声 × 增益」 | 电平表回答「听到的爆没爆」；波形逐文件读一次的前提不变（画效果就得逐段重算） |
| DSP | macOS 自带的音频单元（混响 AUReverb2、失真、EQ、延迟），跑在每条合成音轨已有的 tap 里；导出读同一份合成、挂同样的 tap | 轻量化、白嫖 macOS（AGENTS.md 工程原则 1）；不自写混响；① 做完之后导出天然带上 |

## 三、实测地基（2026-09-24 两个探针）

探针脚本和原始数据在当时的临时目录里，结论如下（长期约束已抄进对应的架构文档）。

**成片的声音能不能离线读预览那份混音（第 ① 步）：能。**
- 速度：10 分钟、30 段读 1.7 秒（357 倍实时，峰值 31MB）；30 分钟、60 段、35 条合成音轨、混着
  48k / 44.1k 单声道 / mp3 读 25 秒（75 倍实时，79MB）；挂着 tap 也读得完、不卡。
- 和以前的成片比：音量、渐变、曲线、推子、上层轨 / 音频轨 ≤ 0.01 dB；变速段换成了预览的
  `.spectral`（语音逐窗差 1 dB 上下）；**单声道素材成片响 3 dB**（以前 ffmpeg 转立体声 −3 dB，
  预览一直是满的）。位置按合成的 1/600 秒，不再按整毫秒。
- 读到最后一个有声音的采样就停，要自己补到时间线那么长。
- **顺带查出一个老 bug**：预览换 mix 的三个入口拿没展开转场的用户状态铺斜坡，接缝上声音掉下去
  （[案例](../bugfixes/2026-09-24-preview-mix-ignores-transition-expansion.md)）—— 不修的话「成片 = 预览」
  在转场上不成立，所以同一刀修掉。

**效果能不能跑在 tap 里（第 ② 步）：能。**
- tap 里用 `AudioUnitRender` 跑苹果自带的效果单元：离线读、静音的实时播放器都真的改了声音；
  两次离线读**逐位相同**，按 512 / 4096 / 4474 帧分块渲染也逐位相同 —— 预览（实时 4474 帧一块）
  和成片（离线 512 帧一块）跑的是同一个 DSP。所有单元延迟为 0。
- 播放中每 100ms 改一次参数、每 500ms 换一份 audioMix（复用同一个 tap）都不卡；每次新建 tap
  照旧会卡（10 次累计 2.2 秒）。
- **seek 之后旧的混响会拖进新位置**：要在拿到源音频之后、渲染之前比一下时间戳，跳了就
  `AudioUnitReset`；暂停 / seek 之后的空转回调（时长 0）不许跑效果单元，否则会把混响的尾巴耗掉。
- **余音**：同一条合成音轨上两段之间的空档里 tap 照常被调，尾巴出得来；但**一条合成音轨最后一段
  之后 tap 就不再被调**，`insertEmptyTimeRange` 补的空段会被静默丢掉 —— 要垫一截真素材（同一个
  素材文件，格式天然一致；tap 不用它的内容）。
- **空档里的音量**：AVFoundation 在空档里一直沿用空档开头那一刻的音量，空档中间设的点不按时生效。
  所以挂了场景的合成音轨，段的增益在 tap 里乘（效果之前），AVFoundation 那边只放推子（常数）。
- 候选单元：AUReverb2（13 个预设，参数可调，支持单声道；**载入预设后 Dry/Wet 读回来是 0.5**，
  所以参数一律自己设）、AUNBandEQ（8 段，含高低通 / 搁架 / 参量）、AUDistortion（软削波等）、
  AUDelay（延时 0–2 秒、反馈、低通）。`AVAudioUnitReverb` 在 macOS 上包的是 MatrixReverb，不支持单声道。
- AVAudioEngine 手动渲染也能跑，但单声道格式下 `connect` 抛 ObjC 异常直接崩 —— **选裸的
  `AudioUnitRender`**，一个场景只建它用得到的几个单元。

## 四、分刀（一个 PR，多个 commit）

1. 写代码的规范 + 行数守卫（用户同一条消息里要的，已提交）。
2. 本文档。
3. **成片声音改从预览混音读出**：新文件做离线混音；导出图删掉整条声音链；检查改成对新管线；
   阻塞读取挪到 `MediaReadQueue`。落到：新的架构文档 + audio-fades / volume-curve / mixer /
   transition-handles / blocking-media-reads 里「两条管线」的段落。
4. 模型：段上的声音场景（格式升一版、按需写键；分割 / 分离音频 / 选段导出带着走）。
5. 预览：tap 里跑效果、余音越过段尾、效果排在段增益之后。
6. 界面：检查器那一块、块上的图标、框选批量套用、两张字符串表。
7. 文档与回归清单。
